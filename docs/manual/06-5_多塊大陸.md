# 06-5｜多塊大陸（分支章節）

> 修正第 06-4 章第 3 節（高度圖只有中心一塊大陸）。存檔改第 56 版（地圖改變）。小地圖不變。
> 使用者 2026-11-11 試玩回饋第 6、7 項：創造的世界不像一個大陸；應該像現實一樣有多個大陸。
> 參考：Fantasy Map Simulator、WorldBox 的世界生成（幾塊大陸各自有海岸線、半島與海灣，大陸之間是海峽與大洋）。

## 1｜大陸

- **塊數**【TEMP】：中地圖 2 塊、大地圖 3～4 塊、巨大地圖 4～6 塊。
- **位置**：中心落在地圖四邊各 18% 內側，彼此至少相隔「每塊大陸平均寬度」的 85%（試 48 次）。
- **大小與形狀**：半徑依每塊平均面積 ×0.7～1.0，長寬比 0.7～1.4；座標先用平滑雜訊扭曲約 ±2 格，海岸線因此有半島與海灣，不是圓形。

## 2｜高度

- 高度＝起伏雜訊（三層，同 06-4）佔 40%【TEMP】＋大陸棚（離最近大陸中心越遠越低）佔 60%。
- **海峽**：離兩塊大陸差不多近的地方（大陸棚值相差不到 260【TEMP】）壓低成海，大陸不會連成一片。
- 地圖四邊兩格內往下壓，外圍一定是海。
- 海平面：最高的 44%【TEMP】是陸地（原 55%），留出海峽與大洋。
- 丘陵、河流、淺灘、森林濕度、礦脈照 06-4（山地多在大陸內部）。

## 3｜影響

- 遷徙不跨海，每塊大陸上的開局聚落各自發展（開局聚落照舊隨機放在陸地上）。
- 同種子同地圖（地理流的實體局部亂數）。
