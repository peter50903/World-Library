# 04-2｜存檔精簡（分支章節，接續 04-1）

> 使用者 2026-10-22：存檔太大就精簡（「如果你覺得有必要就做吧」）；大多數人只是統計數字。

## 規則

- **出生、老死合計**：每個聚落（或途中隊伍）每週的出生、自然死亡各合計一筆事件，人數＝事件人數；
  死亡事件註明年齡範圍。週帳對帳改為「有出生（死亡）就恰好一筆、人數相等」。世界紀錄顯示「某村本週出生 3 人」。
- **正式史庫不另存**：讀檔時由較早事件＋近期週報經提交時同一個轉換器重建並逐筆驗證；
  只有較早的途中餓死要另記當時隊伍所在格（`EarlierEventCells`）。
- 存檔第 22 版。

## 未做（評估後暫緩）

- 存檔壓縮（gzip）：會動到 Godot 存檔槽與冒煙測試，等存檔再變大時再做。
- 來源帳只記有變動的來源：牽動週結算、讀檔與不變量，暫緩。
