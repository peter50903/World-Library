# 05｜Godot 控制台分離視窗與擺位（原 C03）

> 狀態：**待使用者實測**。前置：無。不碰模擬核心。可與第 02～04 章平行做。

## 使用者先做（約 10 分鐘）

1. 取得最新 main，用 Godot 4.7.2 .NET 開 `godot/project.godot`，按 F5。
2. 主視窗不要最大化（已滿版就雙擊標題列還原），拖到螢幕中間偏右。
3. 按「開啟世界控制台」，控制台出現在：① 主視窗外旁邊（工作列多一個視窗）② 蓋在地圖中間 ③ 只露出一部分 ④ 完全看不到。
4. 拖動控制台標題列能否拖出主視窗？拖右下角能否縮放？
5. 按控制台 X 能否關閉、主畫面按鈕是否恢復？再按一次是否正常重開？
6. （有空）主視窗拖到螢幕最左邊、或第二台螢幕，重測 3～5。

回報：作業系統、解析度與縮放比例、第 3 步是哪一種、第 4、5 步結果、整個螢幕的截圖。只需描述看到什麼。
即使回報是 ① 且一切正常，仍做本章（小螢幕擺位、重開尺寸、主畫面資訊、冒煙假通過都要修），PR 標註「實測未重現嵌入問題」。

## 規則

- 控制項放在可另開、可獨立移動縮放的視窗，地圖維持全寬；內容過長捲動；主畫面有開關入口；關閉不改世界與播放。
- 邊距 12、偏好 750×780、最小 440×400、字體倍率 1.0～1.35 都是 TEMP 顯示參數，集中在純函式檔常數並標 `TEMP`，不進設定檔。
- 主畫面日期／摘要與控制台內容來自同一次 Core 讀取。
- 冒煙必須真的會失敗，不接受恆真斷言。

## 玩家看得到

- 控制台一定是分離的作業系統視窗：可拖出主視窗、不被裁切；夠寬時停靠在主視窗旁不蓋地圖；螢幕太小時至少整個在可用螢幕內，標題列與 X 看得到。
- 每次開啟重新計算尺寸；已開時再按主畫面按鈕會把它擺回可見位置。
- 控制台關著時，主畫面仍顯示：世界日期與播放狀態一行、選格摘要一行、重大事件提示按鈕。

## 實作

1. `godot/project.godot` [display] 加 `window/subwindows/embed_subwindows=false`；以 `_controlsWindow.IsEmbedded()` 判斷實際模式（headless 可能仍嵌入，實測結果寫進 PR）。
2. 新增純 C# 檔 `godot/Scripts/ControlWindowPlacement.cs`（不引用 Godot，用自訂矩形）：`Place(主視窗, 可用區, 偏好, 最小, 邊距, 是否嵌入) → 視窗矩形`。分離模式：左右較寬一側放得下最小寬就停靠，否則放可用區內靠右；嵌入模式：可用區＝主視窗本身。結果一定完整在可用區內、尺寸 ≥ 1。測試專案用 `Compile Include … Link` 連結（比照 `PlaybackClock.cs`）。
3. `ShowControlsWindow` 每次開啟與已開時再按都從偏好尺寸重算、套用 `Place`；不再永久改寫 `MinSize`；刪除 `PopupCentered` 後備。
4. 主畫面標題區與地圖之間加一列：日期＋播放狀態、選格摘要、`_alertButton` 搬到此列；完整狀態與點格資訊留在控制台。在 `Refresh`／`OnCellSelected` 同處寫入。
5. 改寫 `VerifyControlsWindowSmoke`：用 `EmitSignal(Window.SignalName.CloseRequested)` 關閉；設 `Size` 後等一 frame 驗 `ContentScaleFactor` 自動變化；驗地圖寬；縮小關閉後重開恢復偏好尺寸；移到可用區外再按會擺回；主畫面資訊列與 Core 日期相同。輸出 `WORLD_SIM_WINDOW_OK: EmbedSetting=0 Embedded=<0或1> MapWide=1 CloseX=1 Reopen=1 Replace=1 Autoscale=1 MainInfo=1`，CI 同步改 grep。
6. README 的控制台說明改寫為實測行為。

## 驗收

- `ControlWindowPlacementTests`：① 可用 2560×1400、主視窗 x=560 寬 1440、分離→在右側不重疊、右緣 ≤ 2560；② 1920×1040、主視窗 x=240 寬 1440→可重疊但在可用區內；③ 3840 寬、主視窗靠左→寬度＝750；④ 嵌入、主視窗 1440×900→結果在 (0,0,1440,900) 內；⑤ 可用 800×600→仍在區內、尺寸 ≥ 1；⑥ 第二螢幕起點 x=−1920→在該區內。
- Godot 冒煙：embed 設定為 false；支援子視窗時 `IsEmbedded()` 為 false；開關時地圖寬 ≥ 主視窗可見寬 × 0.9；X 後不可見且按鈕恢復；縮到 450 寬→關→重開回到重算值；移出可用區再按回到區內。
- 控制台關著推進 1 日，主畫面日期含正確日數；點聚落後摘要含聚落名；重大事件時提示按鈕可見。
- 開關縮放前後 `StateFingerprint` 相同；其他冒煙照舊。
- 使用者用「使用者先做」步驟重測結果為 ①、拖動 X 重開正常，本章才算完成。
