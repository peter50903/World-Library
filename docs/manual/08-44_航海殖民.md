# 08-44｜航海殖民（分支章節）

> 08-42 之後人類還完全過不了海：遷徙與開拓只走陸路，別的大陸與無人島永遠沒有人去。本章讓出得了海的聚落搭船到海外開拓，
> 海上的怪物擋住航路——人類與怪物在海上爭地（總綱第 1 節的兩個重點）。
> 修改：07 c 節（開拓選址）、08-42（海上怪物也擋開拓船）。存檔第 101 版（規則改變）。

## 1｜規則【TEMP】

- 開拓隊照舊先在陸路 `FoundingSearchMaxSteps` 格內找空地；**找不到**時，出得了海的聚落改搭船：
  有港口的走 16 格海路內、只會基礎造船又靠海的走 8 格內。
- 沿海（八方向、只走海）找靠岸的**海外**空地——陸路走不到的陸地，選址條件與陸路開拓相同（有水源、不在開墾地、不在怪物佔的地、養得起），
  挑可持續餘量最大的。
- 航路避開海上怪物佔的海；家門口的海被佔滿就出不了海，要先海戰把怪物打退。
- 航程：每週一格（上船、沿途每一格海、上岸），與陸路一樣不瞬移（M1_MIG）；途中照舊吃自己帶的糧，所以航程不能太遠。
- 事件寫「附近沒有空地，搭船渡海前往……開拓新聚落」。

## 2｜存檔驗證

- 途中隊伍的路線每一步要走得通：陸路路線段，或上下船（陸地與相鄰的海），或海上一步（相鄰的兩格海）。

## 3｜驗收

- 測試 `DemoSeaColonyTests`：上岸的地方是陸路走不到的海外、路線每一步走得通、怪物佔滿家門口的海就出不了海。
