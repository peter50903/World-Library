# 08-12｜聚落成長與聚集（分支章節，修正 08-6 c 節農田供應、08-1 擁擠外移只開拓）

> 試玩回饋一之後的變化報告：小聚落不再餓死，但每個聚落一直停在 10～20 人，沒有聚落長到城鎮（60 人），
> 第 3 階技術永遠不開放，第 70 年後世界又趨平。本章讓聚落長大、人往養得起的地方聚。
> 參考：WorldBox 人口流向大城、CK3 人口往發展高的地方集中、世紀帝國農田是主要糧食來源。數值【TEMP】登錄 D08-12。

## 1｜農田是主要糧食（修正 08-6 c 節）

- 農田每格每週供應 24→40（草原野採 8、森林 20、河流 5）。一圈六塊農田約 240／週，約養 60 人＝城鎮門檻。
- 開墾規則不變（會作物栽培、相鄰草原、每週 2%）。

## 2｜聚集：擁擠時先搬進養得起的聚落（修正 08-1：擁擠外移只開拓）

- 擁擠分家（人口接近附近來源上限、還沒挨餓）時，先找：已知、走得到（消息已傳到）、來源餘量至少是這批人每週需求 2 倍的聚落，搬進去。
- 找不到才照舊開拓新聚落。缺糧外移規則不變。
- 搬遷事件是根因（有週帳的擁擠證據），編年史與聚落小史照舊記錄。

## 3｜之後

- 技術效果（灌溉、輪作提高農田、乾燥保存降低腐敗…）。
- 農田可及範圍擴大（村莊以上可開墾兩格內），讓城鎮長到城市。
