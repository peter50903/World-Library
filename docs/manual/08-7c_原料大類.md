# 08-7c｜原料大類（分支章節）

> 使用者 2026-10-23：原料切太細會讓運作太複雜、技術難以達成，採 Claude 推薦的大類方案。
> 本章修正 08-7a 第 2 節「研究資源」與第 08-9 章 A2 的原料判定；數值與歸類一律【TEMP】。

## 1｜原則

- **背景層（聚落）只看 7 大類原料**，與文化信仰「背景人口只存比例」同一思路：糧食、木材、石材、礦石、金屬、獸產、植物材料；魔法原料另列，魔法章節前不出現。
- **細項是加工品**：布、皮革、羊皮紙、鐵錠等不另存原料，而是「大類＋已會的技術」就算有。例：會鞣革＋有獸產＝有皮革、羊皮紙；會織造＋有植物材料＝有布；會高溫冶煉＋有礦石＝有鐵錠。
- **只有重要人物、城市工坊、商隊交易時才細分到具體物品**（第 09 章以後）。
- 設定檔各技術的 ResearchResourceCost 保留細項 ID（日後經濟要用），研究判定改查正式設定新分頁 `10T_原料大類`：細項 → 大類 ＋ 需要的技術。

## 2｜大類與取得條件

| 大類 | 包含的細項 | 聚落取得條件（目前） |
|---|---|---|
| 糧食 | 穀物、蔬果 | 有存糧 |
| 木材 | 木材 | 可及森林 |
| 石材 | 石材 | 可及丘陵（地形尚無，第 08-9 章 D1） |
| 礦石 | 鐵礦、煤、寶石、鹽 | 勢力範圍內有礦脈（尚無，D1） |
| 金屬 | 鐵錠、銀錠（需高溫冶煉） | 有礦石 |
| 獸產 | 獸肉、獸皮、皮革（需鞣革）、羊皮紙（需鞣革） | 野生動物或牧群（尚無，C1） |
| 植物材料 | 纖維、草藥、布（需織造）、黏土、沙、水 | 可及森林或草原，或可取水 |
| 魔法原料 | 魔晶、魔法木 | 魔法章節前不出現 |

- 和 A2 的差異：黏土、沙、水不再分開判定（併入植物材料）；鹽改屬礦石；細項的地形條件都由所屬大類決定。
- 原料仍暫不扣除（倉儲與生產在第 09 章，屆時以大類記帳）。
