# 08-6｜時代、聚落等級與知識樹（設計章，分支章節）

> 使用者 2026-10-23 的構想與裁決（四項概念問題皆採建議）。數值一律【TEMP】由 Claude 定。

## 時代

| 時代 | 開始條件 | 新增內容 |
|---|---|---|
| 希望時代（目前） | 開局 | 不餓死、只有老死；採集為生 |
| 開拓時代 | 任一聚落習得知識樹上任一技術 | 學習知識的時代；人類生活圈外出現野生動物攻擊事件；天災事件；地下城出現；基礎的文化與信仰 |
| 征服時代 | 第一個王國成立（首都出現） | 完整社會結構、國家權力分配（王國、帝國）；神可以影響世界 |

- 時代是全世界共用的（以第一個達成條件的聚落為準），記入正式世界史。
- 開拓時代起恢復餓死（希望時代的「不餓死」是時代特性）。

## 知識樹（第一版，只做開拓時代需要的）

- 技術：農耕（草原開墾成農田，提高食物上限）、木工（木匠；村莊條件）、鍛造（鐵匠；工具提高採集效率）、石工（石匠；城牆）。
- 取得：經過一段時間自動學會。每個聚落各自累積「研究進度」；每週進度＝基礎量＋該產業從業者人數×權重＋學者人數×權重【TEMP】。
- 專業知識持有者（木匠、鐵匠、石匠、學者…）是有名有姓的代表人物（第 08-5 章），人數影響推進速度。
- 知識的傳播：持有者透過婚嫁與遷徙搬進別的聚落時帶過去，比自行研究快。

## 實作順序

1. 知識進度與第一個技術（農耕）＋開拓時代開始（世界史記一筆）。
2. 木工與木匠、聚落等級「村莊」改由木匠決定。
3. 農田開墾（第 08 章 a 節的土地開發狀態接上真正的開墾行動）、開拓時代恢復餓死。
4. 鍛造與工具、野生動物攻擊、天災、地下城、文化與信仰（各自一章）。
