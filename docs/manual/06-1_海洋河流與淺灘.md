# 06-1｜海洋、河流與淺灘（第 06 章 a 節的分支章節）

## 概念（使用者，已定案）

- **海洋與河流要分清楚**：河流可以有深淺之分；海洋只有深水。海洋要像一片海，不能和河流長得很像、也不能隨意散落在陸地中間。
- **淺灘**讓人不用船就能涉水過河，所以淺灘兩端都要連到陸地才有價值。淺灘的圖案要和一般河流不同，看得出是淺水。

## 驗收

- 61 個種子：每欄最南一列是海、海深 1～2 列；所有水域格不是海就是河；海沒有淺灘。
