# 12-2f｜怪物等級改為層數；終章寫出險境與最強的軍隊（分支章節）

> 修正 12-2c（怪物等級＝層數＋1）。存檔改第 72 版（規則改變）。
> 來源：12-2e 之後中地圖一百年有兩個地下城，都是三層（4 級怪物），要三項裝備技術的士兵才殺得光，
> 百年內沒有勢力打得贏；地下城數量滿了又永遠不被殺光，「怪物討伐」這條故事線仍然停擺。數值由 Claude 定案（總綱第 3 節），全部【TEMP】。

## 1｜規則

- **怪物等級＝地下城層數**（1～3 級；原本層數＋1，2～4 級）。士兵等級照舊：1＋弓術、武器鍛造、皮甲、基礎附魔各 +1，英雄在世 +1，奇蹟時代 +1。
  一層的地下城有士兵就殺得光；三層的要兩項裝備技術（或一項加英雄）。
- 襲擊與討伐的交戰算法照 12-2c（怪物等級降低，村民的死傷也跟著少）。

## 2｜玩家看到

- 史書終章多兩行：
  - **險境**：世上的每個地下城（層數，幾級怪物幾隻，或沉寂中）。
  - **最強的軍隊**：出兵時最強的聚落（勢力的最上層聚落帶整個勢力的士兵）與士兵的等級、人數；沒有任何士兵時寫「世上還沒有軍隊」。
- 驗證：CI「中地圖史書摘要」多列險境與軍隊兩行；地下城被殺光時，卷中寫出「某洞窟的怪物被殺光」與之後的英雄、傳說物品。
