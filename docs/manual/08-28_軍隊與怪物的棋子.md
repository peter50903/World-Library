## 1｜棋子

仿 CK3 的軍隊：地上的影子、染色的木底座、中間的士兵（怪物是紅底骷髏）、金邊，下方的數量牌；直徑 **30 像素**【TEMP】，固定大小，任何縮放都看得清楚。

## 2｜什麼時候出現

| 情形 | 棋子 | 怎麼走 |
|---|---|---|
| 征服戰爭、獨立戰爭、內戰（戰線） | 攻方：勢力色士兵＋兵力；守方：守在目標旁（小一點） | 開戰第一次看到時，攻方從出兵地沿行軍路線走到圍城處（**2.6 秒**【TEMP】，真實時間），之後停在那裡直到戰爭結束 |
| 怪物襲擊 | 紅底骷髏＋巢穴裡的怪物數 | 交戰動畫（4 秒）裡從最近的地下城沿紅色箭頭走到聚落 |
| 獸潮 | 同上，大 1.25 倍 | 同上 |
| 出兵討伐地下城 | 士兵＋出征的士兵數 | 從聚落走到地下城 |

- 讀檔或換世界時已經在打的戰爭不重播行軍。
- 跟野獸的戰鬥照 08-18k 不畫。
