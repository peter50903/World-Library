# 08-20a｜2D 等角插畫方向（分支章節）

> 修正第 08-20 章（3D 原型）。使用者 2026-11-14：3D 程式拼的模型細化後仍然粗糙、跟示意圖差距大；改用**偽 3D：用 2D 表現**；新素材照原本流程進 `assets/manifest.csv` 與素材收件匣。
> 本章只定方向、規格與第七批素材；正式地圖仍是現在的畫面，原型做好、試看定案後才換，並修改總綱第 1、7 節的美術基調。

## 1｜為什麼不用 3D

- 示意圖接近精細插畫（倒角、木紋石紋、角落陰影、每棟房子不同）；程式拼方塊、斜頂、圓柱到不了那種質感。
- 真的 3D 模型要 3D 美術或付費的 AI 3D 工具（依總綱第 5 節，付費要使用者同意）。
- GPT 能照示意圖畫出同樣精細度的 2D 圖：建築與景物交給 GPT，地形與厚度由程式畫。

## 2｜做法

- **畫面投影**：正方形格不變，只在畫面上轉 45 度、壓成 2:1 菱形（標準 2:1 等角）；最大放大時一格＝256×128 像素【TEMP】。
- **建築、樹、岩石、水車等**：GPT 等角插畫精靈圖（第七批），底部中心對齊所在位置，依「列＋欄」由後往前排序繪製；同一張左右翻轉可得另一個方向。
- **地形**：程式把俯視的無縫紋理斜貼到菱形頂面；地塊的厚度（土層側面）、河道下陷、海岸台階由程式畫，明暗依固定光向（左上）。
- **地圖資訊**：勢力色塊與邊界、圖示、箭頭、交叉劍、名牌照現在的方式疊在 2D 上面。
- **縮放**：精靈圖不放大超過原圖；拉遠改畫色塊（使用者 2026-11-14）。
- **點選**：螢幕座標換算回格子；點到建築依精靈圖範圍判斷屬於哪個聚落。
- **素材缺少時**：建築畫成色塊、地形畫純色，不會無法啟動（總綱第 7 節）。

## 3｜第七批素材（`assets/GPT_第七批_等角插畫.md`，35 項）

- 房屋 6、城鎮防禦 4、市集與廣場 4、農村 6（含 4 幀水車）、樹木與岩石 8、地形紋理 7。
- 共同規格：照示意圖畫風；2:1 等角、鏡頭從東南往西北看；光從左上；不畫落地陰影；透明背景；以 1024 繪製，匯入縮到成品尺寸。
- 匯入（`tools/art_inbox.py`）：類型「等角精靈」清掉平底色、取不透明範圍、等比平滑縮放、底部置中（動畫依 4 格）；「等角紋理」平滑縮放並融合接縫（土層側面只融合左右）。

## 4｜原型（功能列「等角」）

- 同 08-20 的 16×12 小場景；依「欄＋列」由後往前一格一格畫：四個三角面的頂面（中心起伏、各面依光向明暗，有紋理就貼紋理）、前方的東面與南面側面（有土層紋理就貼，沒有就畫草皮、表土、深土三層）、水面（比河岸低、紋理緩慢流動）。
- 淡格線、水陸交界的浪花；勢力半透明菱形與兩岸邊界；名牌、工作地圖示、戰爭示意、選取外框。
- 精靈圖依位置由後往前畫，先畫落地陰影；有素材就貼圖（可左右翻轉、水車 4 幀），沒有就畫等角色塊（房子加斜頂）。
- 倍率 0.18～1【TEMP】：0.45 以下省略木箱、灌木、乾草堆；0.32 以下改畫色塊（聚落佔的格是勢力色方塊）。
- 點選：先打精靈圖範圍（由前往後），再打地塊（由前往後找第一個包含滑鼠的頂面或側面）。
- 畫面左下顯示還沒有素材的精靈圖種類數。
