# 08-10k｜世襲取名避開這一脈用過的名（分支章節）

> 修正 08-10g（世襲的人名只避開父母的名）。存檔改第 74 版（規則改變）。
> 來源：百年史書的家族一行出現「瓦爾→瑪拉→芙蕾→薇拉→瓦爾」，家譜裡兩個同名同姓的人分不清。

## 1｜規則

- 繼承人與領袖子女出身的英雄取名時，避開：父母與歷代祖先的名，以及父母其他子女（兄弟姊妹）的名。
- 名字照舊由這個人自己的亂數抽（CHARACTER 流實體局部亂數）；抽 32 次都撞名才改用一般人名（機率可忽略）。
- 同一週裡同時取名的兄弟姊妹（例：繼承人與英雄同一週出現）仍可能同名，暫不處理。
- 實作：Core `DemoNames.PersonOfHouse(…, avoidGiven)`、`DemoHumanLifecycle.Apply(…, houseGiven)`、`DemoObserverWorld.HouseGivenNames`。
