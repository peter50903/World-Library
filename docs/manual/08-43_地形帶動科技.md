# 08-43｜地形帶動科技（分支章節）

> 使用者 2026-11-25：「加一條地形會影響勢力的科技發展，靠海、河的地方捕魚、造船、航行的技術發展較快，靠山的地方冶鐵、打獵的技術發展較快，諸如此類」。
> 修改：08-7b（研究點）、08-8 B2（文化的研究加成之外再加地形）。存檔第 100 版（規則改變）。

## 1｜規則【TEMP】

聚落本格與周圍一格的地形，讓相應技術的從業者與專家研究點 +30%（同一項技術符合幾種地形只算一次）：

| 地形 | 發展較快的技術 |
| --- | --- |
| 靠水（河、湖、海） | 結網漁撈、造船分支（基礎造船、帆裝、船體、遠洋、大型船塢）、陶瓷 |
| 靠海（再 +20%） | 帆裝與索具、遠洋造船、大型船塢工藝（航行）、鹽漬保存 |
| 靠山（丘陵） | 採礦冶金（採礦、冶煉、冶金、鍛造）、狩獵、弓箭、巡守與圍獵、石造 |
| 靠森林 | 木工、藥學、皮革 |
| 靠草原 | 作物、畜牧、紡織、服裝 |

- 勢力的科技由各聚落研究、鄰近傳播而來，所以沿海的勢力造船航行領先，山地的勢力冶鐵狩獵領先。
- 和文化加成（海之民造船 +25% 等）相加；從業條件（例如造船要靠森林又靠水）不變。
- 聚落詳情多一行「地形：靠海、靠山——……發展較快」。

## 2｜驗收

- 測試 `DemoTerrainResearchTests`：各地形只加自己的技術、靠海另加航行、多種地形不重複加。
