# 08-45｜行軍、野戰與圍城（分支章節）

> 使用者 2026-11-25：「決定該如何優化戰爭的表現，目前看起來還有加強的空間」——規劃分三章：08-45 模擬（本章）、08-46 戰況看得見、08-47 戰爭總覽與戰史。
> 原本宣戰後第一週就在城下交戰、軍隊不會動、一場戰爭只爭一個聚落；本章讓戰爭有行軍、野戰、圍城與逐座佔領，畫面（08-46）才有東西可畫。
> 修改：08-19e（交戰）、08-22a（圍城與戰爭分數）。存檔第 102 版（規則改變）。

## 1｜行軍【TEMP】

- 宣戰後攻方軍隊從首都沿陸路（與遷徙同一套路線段）走向戰爭目標，每週 3 格；陸路不通（隔海、隔河沒有渡口）時取直線。
- 軍隊位置與行軍週數由開戰週與地圖推得，不另存。行軍途中不交戰。

## 2｜野戰【TEMP】

- 守方兵力（含本土加成 125%）至少攻方的 70%，就在半路出城迎擊（行軍週數的一半那週、路線上那一格），打一場野戰：雙方死傷 ×200%，
  地形照 08-22b（守方在丘陵、森林佔便宜，攻方渡河吃虧）。
- 野戰的勝負記在雙方累計死亡裡，影響會戰分數；會戰分數落後時圍城攻不下（08-22a 規則不變）。
- 守方太弱就不出城，等著被圍。

## 3｜圍城與逐座佔領【TEMP】

- 軍隊到了城下才開始圍城、每週交戰；圍城週數照 08-22a（依層級與城牆）。
- 攻下戰爭目標後，接著圍攻守方在目標 4 格內最近的聚落（每座從上一座攻陷那週算起），最多再佔 3 座；每座戰爭分數 +10。
  交戰的守方死傷算在被圍的那一座。
- 議和只割讓戰爭目標，其他被佔的聚落歸還（佔領由戰爭推得，戰爭結束就消失）。

## 4｜相容

- 沒有地圖時（測試）不行軍：開戰下一週就在城下交戰，與舊規則相同。

## 5｜驗收

- 測試 `DemoCampaignTests`：路線與行軍週數、半路野戰、守方太弱不出城、到城下才圍城；攻下目標後接著佔領附近的聚落、分數 +10、議和只割讓目標。
- 平衡測試（`balance`）看戰爭長度與死傷。
