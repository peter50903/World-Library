# 08-20｜3D 等角原型（分支章節）

> 使用者 2026-11-14：選定新的地圖美術方向（附圖：等角視角、霧面低多邊形建築、柔和日光、看得出厚度的地塊，建築像擺在地圖上的小模型；聚落靠格局辨認；地圖資訊蓋得上去也看得清下面）。
> 決定：用 **3D 正交鏡頭**小規模試看；拉遠時保留色塊顯示（使用者）。**本章只是原型**，不改正式地圖、世界模擬與存檔；試看定案後再另開章節分步換掉正式地圖，並修改總綱第 1、7 節的美術基調。

## 1｜為什麼試 3D 正交

- 2D 等角做地塊厚度、河道下陷、海岸台階，每種地形銜接都要一套接縫圖；光向與角度難以一致；會變化的地圖要另畫變體。
- 3D：厚度與光影由引擎算出；建築由程式用方塊、斜頂、圓柱拼成低多邊形模型（不需要外部模型檔，檔案不變大）；地形、建築建一次放在顯示卡，每幀 CPU 幾乎不做事。
- 格子座標、規則、存檔都不變（一格＝3D 世界的 1×1）；點選改成射線（先打建築、再打地面）。

## 2｜原型內容（功能列「3D」）

- 16×12 手擺小地圖【TEMP】：西側海岸與沙灘、斜穿的河（河道下陷、水面比河岸低）、東北丘陵、兩片森林；整塊地圖像一塊有厚度的模型（側面露出表土、土層、深層土）。
- **木柵城鎮（金柵鎮，金色勢力）**：3×3 格方形木柵、四角角樓、南面城門樓、十字主街、十字路口的紅白攤位與井、四個街區的房子（較大的鎮公所）。
- **河邊農村（河灣村，藍色勢力）**：沿河岸的茅草木屋、河上會轉的水車與磨坊、3×3 方田（金黃麥田、田壟、木圍籬）。
- **勢力**：半透明色塊＋沿格邊的亮色邊界；河不屬於任何勢力，所以兩岸各一條（藍、金）。
- **2D 疊加**：名牌（固定大小）、工作地圖示（農田、伐木場上方的泡泡）、戰爭示意（紅色弧形箭頭＋交叉劍，可開關）、選取外框（等角下的菱形）。
- 光：暖色斜射日光＋天空環境光；柔和陰影只在近景開。
- 不畫人物、動物、怪物。

## 3｜三層【TEMP】（鏡頭可見高度，格）

| 層 | 範圍 | 畫什麼 |
| --- | --- | --- |
| 近景 | 小於 8.5 | 完整模型＋陰影 |
| 區域 | 8.5～14 | 完整模型，關陰影 |
| 戰略 | 14 以上 | 建築與樹改成勢力色的厚方塊（色塊） |

- 縮放 3.5～22；滾輪縮放、右鍵或中鍵拖曳、左鍵點選。

## 4｜試看時要驗證

- **近看**：屋頂、牆、木樁、水車、攤位看得出結構；落地陰影讓建築像擺在地上；海岸、河岸、地圖邊緣看得到厚度；圖示不擋工作地；畫面順暢（記下幀數）。
- **拉遠**：只看格局分得出農村與城鎮；勢力色塊下地形與河仍清楚、邊界連續；切到色塊時不突兀；名牌、圖示不擠。
- **點選**：點屋頂、田、聚落空地都選到同一聚落；點河、無主地選到那一格；被高建築擋住的格也點得到；選取外框正確。
