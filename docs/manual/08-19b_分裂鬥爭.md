## 1｜隸屬改由事件決定

- **自然上級**：照 08-19 第 2 節的層級影響範圍，只用來決定沒有上級的聚落要「歸附」誰。
- **實際隸屬**：由事件推得（歸附、獨立），不另存。勢力範圍、勢力模式、名牌與勢力詳情都用實際隸屬。
- 希望時代沒有歸附與鬥爭。

## 2｜忠誠度（WorldBox）

每個下級每週算一次對上級的忠誠（全部【TEMP】）：

| 因素 | 加減 |
| --- | --- |
| 基本 | +10 |
| 離上級每超過 2 格 | −3 |
| 主要文化不同 | −30 |
| 主要信仰不同 | −15 |
| 人口達上級一半 ／ 比上級多 | −15 ／ −30 |
| 層級不輸上級 | −20 |
| 剛歸附（一年內） | +15 |
| 剛被鎮壓（停戰期內） | +25 |
| 上級直屬超過 5 個，每多一個 | −3 |
| 上級的文化強勢統治 | +10 |

- 聚落詳情列出忠誠總分與每一項因素。

## 3｜獨立派系（十字軍之王）

- **加入**：忠誠低於 0，而且不在停戰期，就加入反上級的「獨立派系」（記事件）。
- **退出**：忠誠回到 10 以上就退出（記事件）。
- 同一個上級底下的成員是同一個派系。首領是人口最多的成員。
- **行動時機**：首領加入滿 26 週（不滿累積滿了），派系就行動。
- **兵力**：
  - 每個聚落的兵力是居民的 1/10，有人就至少 1。
  - 上級方的兵力是上級加上不在派系裡的直屬下級。
  - 派系方的兵力是全部成員的總和。

## 4｜行動：請願或最後通牒

| 派系兵力 ÷ 上級方兵力 | 行動 |
| --- | --- |
| 不到 80% | **請願抗議**（非武力），26 週。期滿 35%（文化不同 +20%）上級讓步。 |
| 80%～150% | **最後通牒被拒**，開打**獨立戰爭**（武力）。 |
| 150% 以上 | **上級接受通牒**，派系和平獨立。 |

## 5｜獨立戰爭

- **交戰**：開戰的下一週起，每週首領與上級交戰。
- **死亡**：依對方兵力決定：1＋對方兵力 ÷ 20 × 0.5～1.5 的運氣，最多留 1 人。
  - 記在與天災同一欄的週帳。
  - 同一週天災、怪物優先。
- **比分**：由交戰事件推得雙方累計死亡（十字軍之王的戰爭比分）。
- **勝負**：
  - 打滿 8 週後，一方累計死亡達另一方的 1.5 倍就分出勝負。
  - 打滿 52 週仍不分勝負時維持原狀（叛軍失敗）。
- **畫面**：上級出兵走向首領的聚落（第 08-18h 章第 3 節）。

## 6｜結果

- **成功**（讓步、接受通牒、戰勝）：
  - 首領與成員一起獨立。
  - 其他成員歸附首領，成立新勢力（WorldBox 叛亂後成立新王國）。
- **失敗**（駁回、戰敗、維持原狀）：
  - 成員被鎮壓、退出派系。
  - 260 週內不會再加入派系，忠誠 +25。
- **其他情況**：
  - 上級成了廢墟或沒人時，下級直接獨立。
  - 首領沒落時，派系瓦解（算失敗）。
- 亂數用事件流的實體局部亂數（索引＝週次與聚落），不推進計數器，重跑相同。
