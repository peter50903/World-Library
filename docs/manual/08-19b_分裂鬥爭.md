# 08-19b｜分裂鬥爭（分支章節）

> 修正 08-19 第 2 節（隸屬每週依層級重算）。存檔改第 52 版（規則改變）。
> 使用者 2026-11-08：勢力分裂前應該要有分裂鬥爭（武力、非武力）。

## 1｜隸屬改由事件決定

- **自然上級**：照 08-19 第 2 節的層級影響範圍，只當作「想要的上級」。
- **實際隸屬**：由事件推得（歸附、獨立），不另存。勢力範圍、勢力模式、名牌與勢力詳情都用實際隸屬。
- 希望時代沒有歸附與鬥爭。

## 2｜每週的變化

在週結算之後，依聚落編號逐一判斷：

1. **上級沒落**：上級成了廢墟或沒人時，直接獨立，不必鬥爭。
2. **鬥爭中**：期滿時決定成敗（第 4 節）；期滿前不再判斷別的。
3. **歸附**：沒有上級、自然上級存在，而且不會繞成圈時，歸附它（記「歸附」）。
4. **開始鬥爭**：已有上級，但自然上級變了（長到同級以上、離開影響範圍、或另有更近的上級），而且不在冷卻期。
   - 不會立刻脫離，而是開始一場鬥爭。
   - 主要文化與上級不同時一定是**武力抗爭**。
   - 文化相同時 30%【TEMP】武力、其餘是**非武力**（請願與抗議）。

## 3｜武力抗爭的交戰

- **持續**：8 週【TEMP】。開始的下一週起，每週兩邊都有傷亡。
- **傷亡**：
  - 叛離方每 80 人多死 1 人、上級每 150 人多死 1 人【TEMP】，各至少 1 人。
  - 記在與天災同一欄的週帳（「抗爭交戰」事件）。
  - 同一週天災、怪物優先，已經有的聚落不再算交戰。
- **畫面**：上級出兵走向叛離的聚落（第 08-18h 章第 3 節）。

## 4｜成敗

- **武力**：勝率＝叛離方人口 ÷（叛離方＋上級人口），限制在 15%～85%【TEMP】。
- **非武力**：持續 26 週【TEMP】，沒有傷亡。勝率 35%【TEMP】，文化不同再加 20%【TEMP】。
- **成功**：記「獨立」，脫離上級。若之後落在別的上級範圍內，下一週再歸附它。
- **失敗**：記「脫離失敗」，仍隸屬原上級；104 週【TEMP】內不再鬥爭。
- 亂數用事件流的實體局部亂數（索引＝週次與聚落），不推進計數器，重跑相同。

## 5｜事件

| 事件 | 人數欄 | 編年史 |
| --- | --- | --- |
| 歸附 | 上級編號 | 一般（勢力） |
| 武力抗爭、請願抗議 | 上級編號 | 重大（勢力） |
| 抗爭交戰 | 死亡人數 | 一般（勢力） |
| 獨立 | 原上級編號 | 重大（勢力） |
| 脫離失敗 | 上級編號 | 一般（勢力） |

- 全部是根因。歸附、鬥爭、獨立的人數欄必須是另一個聚落的編號。
- 編年史新增「勢力」分類。
- 聚落小史記歸附、鬥爭、獨立與失敗。

## 6｜玩家看到

- 勢力詳情的「勢力」頁加「分裂鬥爭」段：
  - 武力：「⚔ 某村正以武力抗爭，想脫離某鎮（約 N 週後分出勝負）」。
  - 非武力：「✊ 某村正請願抗議，想脫離某鎮（約 N 週後有結果）」。
