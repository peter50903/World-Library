## 規則（已定案）

**宗教與神**
- 宗教與神是不同實體：教義屬於宗教，領域屬於神；創教時依創教者特徵生成一神或多神。
- 信仰值（`Faith`）是唯一的個人信仰強度：低於 50 無正式宗教；50 以上成為某一位神的正式信徒，同時只能信一位神。
- 神的存在取決於信徒：信徒為 0 時神變為不存在（可復甦），至少 1 人時存在；神永遠沒有肉身。
- 神蹟沒有成功率骰：前置合法、信仰力量付足就必定生效。

**文化與語言**
- 九文明種族的文化、語言、宗教彼此獨立；文化緩慢演變、分裂、融合；失傳文化不能原樣復活。
- 語言可演化，滅絕語言的古書不會自動翻譯；語言能力固定三級（不懂／聽說／讀寫）。

**知識與研究**
- 研究：選定合法目標 → 投入真實時間與資源 → 進度累積 → 必定成功；魔法研究只能發現世界本來存在的魔法。
- 文明「知道」某技術不代表每個人都會；知識靠老師、書籍、教育傳播；最後的知情者與載體都消失就失傳。
- 科技上限：蒸汽工業為主體（煤鐵、蒸汽機、工廠、鐵路、蒸汽船、早期火器），只額外允許「進階鋼鐵冶煉」與「電報」。
- 沿用十四個領域技術樹（表 10A–10N）；國家層用聚合摘要，重要人物與組織保存實際持有者。
- 初始文明程度：原始／發展中／成熟，作為整體傾向，各地可有落差。

**工業**
- 工廠四段閘門：掌握原理 → 掌握建廠方法 → 真的蓋好 → 有人力、原料、能源才生產。
- 六大類：冶金、機械、化工、紡織、食品、軍工（造船走船塢）。同類產品免費切換、可並行共用總產能（≤100%）；管理者只定目標，由組織 AI 排產。
- 啟動後機器可自行運轉、專家定期巡檢、需隨規模增加的最低管理人力；只有三種停產原因：遭攻擊損壞、資源不足、人力不足；沒有隨機故障。

**魔法**
- 後天魔法是技能，需先取得知識；施法消耗真實 MP；臨時創造的物質不永久增加資源；不能改寫過去；一般魔法不能隨便復活人。
- 動物不能用魔法；怪物只有天生魔法；魔物＝怪物＋魔化；魔族是文明種族，可學魔法並天生控制魔物。
- 魔法工業需真實魔法知識、設備與魔力來源，不是免費自動化。
