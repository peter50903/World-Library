## 規則（已定案）

**模擬架構**
- 三軸分離：存在值（多顯著）、資料抽象層（展開多細）、執行層（多久更新）彼此獨立。
- 執行層：L0 世界（每年）、L1 國家（每月）、L2 聚落／地區（每週）、L3 角色（依下一個排程行動）、L4 即時場景（暫定 0.5 秒【TEMP】）；重大事件立即處理。
- 抽象層：文明 → 地區 → 人口群體 → 輕量角色 → 事件角色 → 完整角色 → 即時場景；一般人口可聚合，但概念上仍是真實個體。
- 升格只能從既有人數中抽出、符合群體統計，不得多生人口；完整角色資料永久保留，不壓回人口群體。
- 存在值不是主角光環：只影響事件注意度與運算優先度，不加能力或資源。
- 效能：只更新受影響的集合，不做全世界兩兩比對；跨區影響必須經合法渠道。

**觀察者與歷史**
- 觀察者可看完整世界真相與阿卡西紀錄；首頁只顯示高關注項目（重要人物、國家、戰爭、災難），由事件驅動的「觀察者關注索引」排序。
- 第一階段要能回答：發生了什麼、為什麼、造成什麼、某實體經歷了什麼。
- 因果解釋不得憑空編造；「相關」只是查詢層標記，不升為原因。
- 歷史壓縮只改保存粒度，不刪除事實。
