## 1｜人物頁

- **打開方式**：
  - 點地圖上的領袖：有在任的村長時直接開他的人物頁；沒有時開聚落的「代表人物」頁。
  - 聚落「代表人物」頁、人物頁「同僚」頁裡，每個人旁邊有「查看人物 ▸」。
- **分頁**：
  - **人物**：人像、職位與名字、性別與年齡、所屬聚落與層級、任期、文化（含傳統）、信仰、職責；所屬聚落效忠哪個勢力；領袖另寫他統領幾個聚落、是否帶領聚落加入獨立派系。
  - **生平**：小傳（第 08-16 章）。
  - **同僚**：同一聚落的其他代表人物，每人都能再點進去。
- **麵包屑**：回所屬聚落。
- 人物頁只讀世界。卸任或過世的人找不到時不開。

## 2｜世界法則

- **開啟方式**：左下功能列的「世界法則」按鈕打開視窗，每條法則一個勾選框。
- 預設全開，與加入世界法則前完全相同。
- 改了之後從下一個結算週起生效。存檔記下目前的法則，讀檔時還原。

| 法則 | 關閉後 |
| --- | --- |
| 天災 | 地震、龍捲風、隕石與洪水不再發生（熱浪與野火照舊） |
| 地下城與怪物 | 不再出現新的地下城，怪物不再出擊，聚落也不再討伐 |
| 叛亂與獨立 | 不再有人加入獨立派系，也不會有新的請願或獨立戰爭；進行中的照常結束 |
| 野獸襲擊 | 野獸不再在路上襲擊遷徙隊伍 |

- **素材**：按鈕圖示 UI_ICON_LAWS 待製作，缺少時顯示文字「法則」。
