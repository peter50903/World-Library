# 08-10f｜人物進入史書（08-10e 第 2 步之一；分支章節）

> 接續 08-10e 第 3 節第 2 步（補主角）。只改史書的寫法，不改世界規則、不改存檔。
> 來源：城市出兵（08-19i）之後史書有了興衰，但只有地名——「伯恩坡征服了佩林谷」，沒有人。

## 1｜做法

人物全部由既有資料推得：人物登記表（14-1 第 7 項，只增不減）與已提交的事件。

- **勢力大事註明領袖**：征服、獨立、戰爭結局的句子裡，每個聚落第一次出現時註明當時的領袖。
  例：「伯恩坡（哈洛·泰恩）兵臨城下（兵力 57 對 5），柯林菲爾（莉亞·伍德）不戰而降，歸入伯恩坡。」
- **每卷的人物**：任期在這一卷結束（或到最後仍在位）的領袖，任內降服加失去的聚落至少 2 件【TEMP】才寫，
  降服多的在前，每卷最多 3 位【TEMP】。寫在位年份、降服與失去幾個聚落、怎麼離開的（壽終、餓死、死於災禍或兵燹、隨聚落消亡）。
  降服 3 個以上【TEMP】稱「征服者」。
  例：「人物：伯恩坡的征服者哈洛·泰恩（第 55～78 年在位）降服 5 個聚落、失去 2 個聚落，第 78 年壽終（63 歲）。」
- 登記表把戰死與天災記在同一欄，所以史書寫「死於災禍或兵燹」，不硬分。
- 實作：Core `DemoSagaCast`（`LeaderAt`、`Sentence`、`Annotate`、`Rulers`、`ExitText`）。
