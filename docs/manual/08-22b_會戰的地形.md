# 08-22b｜會戰的地形（分支章節）

> 參考 CK3 的戰鬥（08-22 第 2 節第 2 項的第一步）：地形影響會戰。統帥（領袖、英雄）與三階段留待之後。

## 1｜規則【TEMP】

征服戰爭的每週交戰（08-19e、08-22a），攻方對守方造成的死傷依地形打折（守方造成的死傷不變，守方本來就有本土加成）：

| 情況 | 攻方造成的死傷 |
|---|---|
| 戰爭目標在丘陵上（據守丘陵） | ×75% |
| 戰爭目標在森林裡（據守森林） | ×85% |
| 攻方首都到戰爭目標的直線要過河（攻方渡河） | 再 ×80% |

- 打折會讓攻方的會戰分數變低（08-22a），所以據守山地、隔河的目標比較難攻下，圍城也比較容易被拖住。
- 交戰事件的原因寫出地形：「征服戰爭：抵抗某某的大軍（據守丘陵、攻方渡河）」。

## 2｜存檔

會戰的死傷改變：存檔第 78 版。

## 3｜驗證

`DemoConquestTests`：丘陵、森林、渡河的百分比與說明；直線經過河流格才算渡河；沒有地圖時不打折（既有測試不變）。
