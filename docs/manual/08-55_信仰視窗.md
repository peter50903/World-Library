# 08-55｜信仰視窗（分支章節）

> 試玩回饋 2026-11-26 第二次之 1：信仰要跟 CK3 一樣有自己獨立的頁面控制、顯示，才比較好辨識。只改介面。
> 修改：08-16 第 15 節（信仰頁原本在左邊的詳情裡）、08-54（信仰模式點信仰）。

## 1｜參考 CK3

- CK3 的信仰有自己的介面：信仰的符號與名字、所屬宗教、信條與教義、聖地與控制者、信徒。
- 開信仰介面時地圖切到信仰模式。
- 信仰模式點到信仰就開它的介面。

## 2｜信仰視窗【TEMP】

- 打開方式：
  - 功能列「信仰」（圖示 UI_ICON_FAITH 交件前顯示字）。
  - 信仰模式點地圖。
  - 圖例的信仰名。
  - 聖地頁、聚落頁的「信仰：」連結。
- 左邊（寬 280）是全世界的信仰，依家族排：
  - 源頭依創立先後；分裂出來的接在母信仰下面，每一代縮排一層。
  - 每列有信仰符號（信仰色外圈）、名字、信徒數。
  - 失傳的排最後、變淡。
- 右邊是選到的信仰（預設信徒最多的）：
  - 頁首：大符號（84）、名字、信徒數與佔全世界的比例、以它為主要信仰的聚落數、地圖上的顏色。
  - 聖地與控制者：在信徒手中／落在某某（信什麼）手中／已成遺跡；「看聖地」切到信仰模式並移到聖地。
  - 家族：母信仰、分裂出去的信仰（點了換看那一個）。
  - 「在地圖上看」：切到信仰模式，框起這個信仰，它的聖地閃動。
  - 信條與教義、信徒分布、歷史：Core 的信仰頁，同一份內容。
- 視窗開著時每週更新；最大 980×680。

## 3｜驗收

- 冒煙測試 `VerifyFaithSmoke`：打開、左右都有內容、左邊列出世界上每一個信仰、關掉。
- 文字對比檢查涵蓋這個視窗。
- 素材：UI_ICON_FAITH（待製作）。
