# 08-2｜希望時代（第 08 章與 08-1 章的分支章節）

> 修正 08-1「只有老死與飢荒死亡」的目標。效力：總綱 ＞ 本章 ＞ 08-1 ＞ 第 08 章。使用者 2026-10-21 給定概念，程式與數值由 Claude 決定。

## 概念（使用者，已定案）

世界演化以**時代**區分，目前是第一個時代：**希望時代**。
- 沒有災難、沒有紛爭、沒有危險；食物充足，可以自由婚育、自由遷徙。
- 除了**老死**之外沒有其他死亡（不會餓死），世界不應三兩下就滅亡。
- 期望走向：採集 → 生育 → 擁擠就遷徙建村 → 擴散到地圖承載上限 → 之後大致維持（人口靠出生放慢與老死平衡）。
- 之後的時代（災害、紛爭、疾病等）由後續章節加入；本章只定希望時代。
