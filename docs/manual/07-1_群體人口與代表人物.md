# 07-1｜群體人口與代表人物（第 07 章的分支章節）

> 修正第 07 章「每個人都是獨立個體」。效力：總綱 ＞ 本章 ＞ 第 07 章。使用者 2026-10-22 定案概念；程式與數值開工時由 Claude 決定。

## 概念（使用者，已定案）

- 世界要能容納幾萬到幾百萬人，所以**絕大多數人只是統計數字**（依聚落、年齡層、性別等分組的人數），只有少數人是有名有姓的個體。
- 只需要知道聚落裡**重要的人**：權力者（例如村長、族長），以及各產業的代表人物。
- 聚落發展成都市等大型生活圈時，依人數多寡只顯示**前幾大的代表人物**。

## 待開工時補齊（Claude 決定，標【TEMP】）

- 群體人口的分組（年齡層、性別、職業）與每週／每月的出生、老死、遷徙機率計算；守恆仍由真實事件保證，不憑空增減。
- 代表人物的產生、繼任與退場（權力者過世後由誰接任、產業代表如何選出），以及群體與個體之間的轉換（某人被選為代表時從群體中具名化，過世後回到統計）。
- 遷徙與開拓隊：群體人數＋帶隊的代表人物。
- 觀察者介面：聚落詳情顯示人口結構統計與代表人物清單；大型生活圈只列前幾名。
- 與第 13 章「存在值、史庫分層」銜接；地圖大小選擇與效能目標（先訂中地圖約一萬人、快轉順暢）。
- 舊的「每人一筆身分」存檔不轉換，版本太舊即拒讀。
