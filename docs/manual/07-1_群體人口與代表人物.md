# 07-1｜群體人口與代表人物（第 07 章的分支章節）

> 修正第 07 章「每個人都是獨立個體」。效力：總綱 ＞ 本章 ＞ 第 07 章。使用者 2026-10-22 定案概念；程式與數值開工時由 Claude 決定。

## 概念（使用者，已定案）

- 世界要能容納幾萬到幾百萬人，所以**絕大多數人只是統計數字**（依聚落、年齡層、性別等分組的人數），只有少數人是有名有姓的個體。
- 只需要知道聚落裡**重要的人**：權力者（例如村長、族長），以及各產業的代表人物。
- 聚落發展成都市等大型生活圈時，依人數多寡只顯示**前幾大的代表人物**。

## 命名（使用者 2026-10-22 定案）

- 風格：**西式奇幻音譯**（例：艾爾溫、卡洛斯、索倫堡）。
- 長度：**每個名字不超過六個字**；人名「名·姓」整體計算，不含間隔號。
- 做法（Claude 定案）：正式設定檔放詞素表（音節、地形詞、聚落後綴、修飾詞，可請 GPT 發想、使用者挑選），以專屬命名亂數流組合，同種子同名；地名取自地形與母村（新村可沿用母村名加修飾）、人名繼承家族姓氏；重要人物可依真實事蹟得到稱號；同區避免重名、過濾不雅組合；名字只是標籤，身分以實體 ID 為準。AI 不決定名字，只可做選用的文字潤飾（沒有 API 金鑰就不啟用）。

## 切片

### a｜群體人口核心

- 人口改為群體：地點（聚落／途中隊伍）×出生年×性別記人數；懷孕依地點×到期週記數；不建立個體、不配實體 ID（`DemoCohortDemography`）。
- 生死：每個年齡群每週抽一次二項分布（自然死亡依 39C 年齡風險，希望時代只有老年）；到期懷孕分娩、性別各半；流產；受孕只在定居聚落，可受孕伴侶＝育齡女性與可配對男性較小者－已懷孕，數量不超過可預留的口糧（第 08-3 章規則改為一次算出可受孕數）。
- 遷徙：`DemoCohortMigration` 規劃出發的年齡群（留育齡女性與可配對男性、開拓帶兩對、依比例、懷孕等比例隨行；婚嫁一人）；結算與生死套用同一份規劃。
- 事件：每位新生兒、自然死亡者仍各一筆（對帳規則不變），正式史庫只連到聚落。
- 介面：世界總覽、點格詳情、人口診斷改讀群體統計；存檔第 19 版（存群體快照，讀檔逐週重播比對）。
- 驗收：守恆（群體總數＝世界人口、各聚落＝帳上人口）；同配方可重現；存讀檔一致；外移保留規則；多種子百年有出生、只有老死、沒有餓死；第 08 章 M1 正式驗收仍通過。

### b｜代表人物與命名

- 代表人物（有名有姓、配實體 ID、算在年齡群人數裡、不外移）：每個有人的聚落一位村長（最年長的成年人）、一位採集代表（人數最多的壯年年齡群），本週有河海漁獲的聚落再一位漁撈代表；老死或聚落無人即卸任，下週依同規則補任（週報記 `Appointments`／`RepresentativeExits`）。
- 命名：詞素在 `config/demo/names-temp.json`；希望時代的開局聚落以世界種子取名（前綴＋地形後綴），新聚落以歷史種子取名（一半機率沿用母村前綴加方位字，如「新索倫」），人名「名·姓」；全部不超過六字、不重名。
- 介面：點聚落詳情列人口結構與代表人物；聚落小史列就任與卸任。
- 存檔第 20 版。

### c｜地圖大小與效能

- 建立世界時選地圖大小（世界配方的 `MapSize`，舊配方沒有這欄＝小）：小 12×8（預設，完全不變）、中 24×16、大 48×32。海岸深度、淺灘數（每 8 列一個）與開局聚落數依格數倍率放大。
- 介面：「以此種子建立世界」旁的「地圖大小」選單；配方說明列出地圖尺寸（小地圖不列）。
- 效能：人口診斷加 `--map` 與每 10 年耗時；完整長測時跑中、大地圖 30 年並以註記列出。
