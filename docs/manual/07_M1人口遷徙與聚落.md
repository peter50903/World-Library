# 07｜M1 人口生死、遷徙身分守恆、新聚落與佔格

> 本章部分內容已由 08-1 修正（近親排除改為只排除親子、擇偶依年齡、開拓需兩對伴侶、婚嫁遷移）。

> 前置：第 06 章 a～d。對應舊任務 P1.1.05～P1.1.07。規格＋切片層級，開工時補程式落點。

## 規則（已定案）

**人口與生死**
- 出生才建立角色（懷孕期不是角色）；種族出生固定；性別男／女。第一階段測試人口一律 `RACE_HUMAN`，不刪改 `02_種族` 其他列。
- 人口只能由合法出生增加：需合法雙親受孕、孕期、出生事件；人口群體具體化成角色不算出生。
- 每週／每年人口帳：期初＋出生－依原因分類的死亡＋遷入－遷出＝期末；世界總人口的遷徙相互抵銷。人口可增、可減、可停滯；不採固定增長率、不強制回到平衡。
- 生育以 `02_種族` 的 `FertilityBaseMonthly`／`FertilityMode`／`TraitsIncludedInBase` 為最終基準；龍族 `SPECIAL_EVENT` 不得當作零機率或通用生殖。
- **自然死亡率以 39C `LIFE_DEATH_BANDS` 為準**，但仍屬【TEMP】（設定檔該列說明要補【TEMP】）；程式移除自創曲線。
- **開局人口為混齡社會**（年齡層比例【TEMP】）。
- **M2 婚制上線前採 TEMP 穩定配對，排除近親。**
- 嬰兒與兒童吃糧但不是成年勞力。
- 自然死亡依年齡機率，不是壽命到期強制死亡。

**遷徙**
- 缺糧聚落人口沿路線段逐格遷徙，不瞬移；人口從來源扣除、抵達才加入。
- **以整個家庭為單位遷徙**（伴侶與子女同行）；孕婦與嬰兒隨隊攜帶個人身分，不複製、不遺失。
- 途中消耗攜帶糧食，可能途中餓死（記在出發聚落的事件、地點為當週所在格）。

**新聚落與廢棄**
- 新聚落人口全部來自開拓隊，不憑空；建立後佔用該格，該格不再是自然來源。
- **聚落人口歸零滿 N 週（【TEMP】52）自動成為遺跡**並記事件，該格恢復自然產出。

**種族（第一階段只用人類；以下規則供多種族階段沿用）**
- 九文明種族；跨種族生育不產生混血，孩子完整屬於父母其中一方。
- `02_種族` 的典型壽命與月受孕基率是最終基準；只有種族列 `TraitsIncludedInBase` 內含的固定特性不重乘（內含標記只放種族列）。精靈、龍族的長壽與低生育已計入基準。
- 魔族、巨人族個體抽中 `RTRAIT_LONG_LIVED` 時，該個體有效壽命 ×3（不改種族基準、每特性只套一次）。
- 能力範圍見 `02B_種族能力範圍`（0～100 暫定尺度，【TEMP】）。

## 待定值（Claude 定案並標【TEMP】）

孕期（現 39 週）、育齡上下限、開局年齡層比例、近親排除範圍、遷徙觸發門檻、遷徙者挑選方式（以家庭為單位的優先順序）、開拓隊最小人數、選址評分、遺跡週數 52。

## 切片

### a｜生死參數統一與混齡開局（P1.1.05 a/b）
- 自然死亡改讀 39C；開局混齡；TEMP 穩定配對＋排除近親；所有抽樣走第 04 章 a 節協定（新動作代碼）。
- 驗收：多種子 100 年出現出生、老死、餓死三類；無近親配對；人口帳逐週平衡；同配方可重現。

> 狀態：完成（2026-10-21，待合併）。程式落點（Claude 定案）：`DemoHumanRulesSource` 從 02 `RACE_HUMAN`（成年 18、典型壽命 75、月受孕 0.08）、39C `LIFE_DEATH_BANDS`（年度機率依 年齡÷典型壽命 分段，週機率＝1−(1−年)^(7/365)）、39C `REP_MISCARRIAGE`（0.5%／月）與 `config/demo/demography-temp.json`（孕期 39 週、育齡上限 45、開局年齡層 0–17 35%／18–44 45%／45–59 12%／60–79 8%，皆【TEMP】）組成唯一人族規則，自創曲線移除。混齡開局屬於世界，以世界種子 ECOLOGY_INIT 流的實體局部亂數抽（命名空間 `TEMP-HUMAN-OPENING-v1`；索引 1 年齡層＋年齡＋年內出生日、2 性別），同世界種子不同歷史種子開局相同；示範聚落只有 3～8 人，故每聚落第 1、2 人固定為育齡女、男（建村夫婦【TEMP】，年齡仍隨機），其餘依年齡層比例抽；之後生死照舊走歷史種子 POP 流。名冊加 `MotherId`／`BirthFatherId`／`PartnerId`；每週先清除伴侶已死或不同聚落的配對，再依 ID 讓未配對成年女性配給同聚落 ID 最小、未配對、非近親（父母子女、同父或同母手足）的成年男性，不用亂數；受孕只與伴侶。讀檔檢查伴侶互指、異性、成年、非近親。存檔第 12 版。

### b｜遷徙攜帶個人身分（P1.1.06）
- 遷徙隊伍持有成員 ID 清單（以家庭為單位），孕期與年齡隨隊推進；抵達時併入目的聚落名冊。
- **解除「人類繁衍」情境禁止遷徙**；預設可玩模式人口過多時會遷徙而非只能餓死。
- 存檔隨隊伍保存成員；版本＋1。
- 驗收：遷徙前後世界人口身分集合相同（扣除途中死亡與出生）；孕婦途中分娩的新生兒歸隊伍；M1_MIG 通過。

> 狀態：完成（2026-10-21，待合併）。程式落點（Claude 定案）：名冊每人加 `BatchId`（途中所屬隊伍；途中 `SettlementId` 仍是出發聚落）。結算時外移人數上限仍是倖存者÷2，再由 `DemoFamilyMigration` 整戶挑選（家庭＝伴侶＋父或母在內的同住未成年子女；家中最年輕成年人較年輕者先走，放不下的家庭跳過、不拆散；父母都不在的未成年人不單獨走，皆【TEMP】），實際人數可能少於上限；生死階段用同一函式把身分加入隊伍。途中餓死依年齡權重從隊伍成員抽；途中可分娩（新生兒歸隊伍）與自然死亡，記在隊伍帳新欄位 `Births`／`NaturalDeaths`／`HungerDebtRemovedByNaturalDeath`，事件帶隊伍編號；途中不受孕、不新配對【TEMP】；抵達時整隊定居。人類繁衍情境解除遷徙禁令（開拓仍未開，留給 c 節）。讀檔檢查每支途中隊伍的人數＝攜帶身分數。存檔第 13 版。

### c｜新聚落、人工佔格與遺跡（P1.1.07）
- 建村寫入人造佔格；選址需可取水、非主水道、可及自然來源。
- 人口歸零滿 52 週→遺跡事件、移除佔格、恢復自然來源。
- 驗收：M1_SETTLE 通過；遺跡格恢復產出且無人口；新聚落人口來源可追溯到隊伍。

> 狀態：完成（2026-10-21，待合併）。程式落點（Claude 定案）：人造佔格＝已建立且非遺跡的聚落所在格（`DemoWorldSites.OccupiedCells`；讀檔依週次 `OccupiedCellsAtWeek`：第 F 週末建立者第 F＋1 週起佔格，第 R 週末成遺跡者第 R＋1 週起恢復），佔格的自然來源不存在、遺跡格恢復（存量從 0 起）。開拓選址：非水域（主水道是水域）、可取水、空格，共享採集世界另須可及至少一個未被佔用的自然來源；遺跡格不能直接重建【TEMP】。聚落加 `RuinedWeek`；週帳期末人口連續 52 週【TEMP，`config/demo/settlement-temp.json`】為 0 的那一週末成為遺跡（仍有隊伍正前往則延後），記根因事件「成為遺跡」（`TEMP_EV_SETTLEMENT_RUINED`，畫面提示與自動暫停），遺跡不採集、不是遷徙目的地，地圖顯示遺跡圖示；因果索引反向核對該週恰好一筆。人類繁衍情境開啟開拓。存檔第 14 版。
