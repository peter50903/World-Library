# 05-2｜人物與家族頁、史書的名稱連結（08-10e 第 3 步；分支章節）

> 接續 05-1 第 2 節的「還沒做」：已故人物的人物頁、家族頁、史書裡的名稱連結、時代進度條的用語。只改畫面與說明，不改規則、不改存檔。

## 1｜已卸任、已過世的人

- 人物頁（08-19c）原本只打得開在任的人；現在登記表（14-1 第 7 項）上的人都打得開，聚落已成遺跡也一樣。
- 標題寫「（已故）」或「（已卸任）」；「人物」頁寫生卒、結局（壽終、餓死、死於災禍或兵燹、隨聚落消亡）、任期、家族、性格、事蹟；
  「生平」頁只列任內的事。沒有「同僚」頁。

## 2｜家人頁與連結

- 領袖與英雄多一頁「家人」：父母、手足（同一位父母）、子女，每人一列人像，點「查看人物」打開。都沒有就不顯示。
- 「人物」頁底下一排連結：「家族：某某家 ▸」「父親／母親：某某 ▸」。
- 詳情的連結是通用的（`DemoDetailTab.Links`：聚落、人物、家族），之後其他頁也能用。

## 3｜家族頁（十字軍之王的家族）

- 由家族的開創者打開（人物頁的家族連結、史書裡的「某某家」）。
- 「家族」頁：發源地、開創者、傳幾代（歷代家主的名）、現任家主或末代家主與結局（誰接掌）、出過的英雄、傳家寶（傳說物品，08-10i）；
  底下連結到發源地、開創者、現任或末代家主。
- 「成員」頁：每位成員一列——第幾代、職位、名字、任期與結局。
- 「家譜」頁：開創者在最上面，子女依出生先後縮排在父母下面（└、├）。
- 家族全部由登記表的父母欄推得（08-10g），不另存。士兵出身的英雄、農師等其他職位不屬於任何家族。

## 4｜史書的名稱連結

- 史書分頁（05-1）的名稱可以點：聚落（地圖移過去並開詳情）、人物（人物頁，過世的也行）、家族（家族頁）。
- Core 寫一份帶標記的史書（`DemoSaga.WriteMarked`），去掉標記就是原本的純文字史書（`DemoSaga.Write`，文字版與 CI 註記照舊）。
  人物與家族在寫的時候就標記（同名的人也分得開）；聚落名稱不重複，最後統一標記。

## 5｜時代進度條

- 頂部的金色進度條說明改成文明里程碑的用語：「下一個文明里程碑：第一個王國成立（42%）」；全部達成後寫「已全部達成」。

## 6｜素材

- 新增兩列待製作（`assets/manifest.csv`）：`UI_ICON_SCHEMATIC`（色塊檢視）、`UI_ICON_DEVTOOLS`（開發工具）。素材到之前按鈕顯示文字。
