# 08-46｜戰況看得見（分支章節）

> 戰爭表現三章之二（使用者 2026-11-25：戰爭的表現還有加強的空間）。08-45 讓戰爭有行軍、野戰、圍城與逐座佔領，本章把它們畫到政治地圖上（參考 CK3）。
> 修改：08-18m／08-28／08-30 的戰線畫法（征服戰爭改用本章；獨立戰爭、內戰照舊）。只改畫面，存檔不變。

## 1｜戰況（Core 推得，不另存）

- `DemoRealms.Status`／`DemoObserverWorld.WarStatus`：行軍中（軍隊在路線上哪一格、還要幾週到城下）、圍城中（圍哪一座、圍了幾週／要幾週）、佔領完畢。
  規則與 08-45 的交戰、圍城相同。

## 2｜地圖【TEMP】

- **行軍**：沿真的路線（不是直線）畫剩下的路——流動的虛線、末端箭頭；軍隊棋子一週一週往前走（每次移動 0.9 秒平滑），上方寫「行軍・還要 N 週」；守軍守在目標。
- **圍城**：被圍的聚落外面一圈圍城進度環（攻方色，從正上方順時針長），下面寫「圍城 3/6 週」，旁邊架起攻城器械、攻守雙方的軍旗；
  首都到目標淡淡的補給線。
- **逐座佔領**：攻下目標後又佔領的聚落一座一座畫上攻方顏色的佔領斜紋；議和後歸還的斜紋消失。
- **比分條**：放大到 76 像素、寫出戰爭分數（⚔ +35）。
- **野戰**：交戰閃光畫在兩軍相遇的那一格；之後兩年那一格留下淡淡的交叉雙劍與年份（中距離以上），滑鼠移上去看那場野戰。
- 滑鼠在戰爭目標或被圍的聚落上：戰況一句話（行軍中還要幾週／圍城幾週／已佔領幾座）、戰爭分數、兵力、雙方死傷。

## 3｜驗收

- 測試 `DemoCampaignTests.StatusFollowsTheMarchAndTheSiege`；地圖截圖（`map-shot`）看行軍與圍城。
