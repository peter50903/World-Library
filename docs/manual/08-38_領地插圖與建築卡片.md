# 08-38｜領地面板：插圖＋建築卡片（分支章節）

> 使用者 2026-11-19：領地面板「改成 CK3 那種『插圖＋建築卡片』的排法」。修改 08-33 的版面（領地圖＋列表）；
> 沿用 08-33 的原則：只畫有蓋、正在蓋、毀損的建築（沒蓋的不畫），要寫細、要視覺化，卡片越多＝建築越多＝城越大。只改介面，存檔版本不變。

## 1｜大圖視窗（點聚落詳情的縮圖或「打開領地」）

- **上排左邊：插圖**——這個聚落自己的領地圖（08-33 排出來的城牆、街道、建築、農田），鋪滿插圖框（裁掉多的部分；小聚落放大到最接近的整數倍，蓋不滿的邊補草地色），
  左上角寫名稱與「等級｜居民｜建築格」。滾輪縮放、拖曳看其他地方、雙擊回到原樣。
- **上排右邊：領地資訊**——等級圖示與建築格（**一格一格畫出來**：用了的塗金、空的留框；格子數＝等級的建築格），住宅、建材、城防、升級進度（08-36）、建築加成（08-37）。
- **下排：建築卡片**，依分區排：住宅、城牆與塔樓、農田與農舍、城內建築、神殿與學府、兵營與訓練場、城堡與官署、城外資源；每區一個標題，下面一排排卡片（放不下就換行）。

## 2｜一張卡片

- **插圖**：依分區上色的天空與地面，中間是建築的正面像素圖（整數倍放大）；施工中是淡淡的建築加上工地，毀損是廢墟；城牆、農田是一整排牆面、田地。
  左上角狀態圖示（施工中、受損、毀損），右上角數量（同一種完好的建築合成一張「×3」）。
- 名稱、**進度條**（施工中，藍）或**耐久度條**（綠、黃、紅）、狀態（施工中 40%、受損（耐久 60%）、毀損（耐久度歸零））、作用（08-37，例如「研究 +15%」）。
- 框的顏色看狀態：完好金框、受損橘框、施工中藍框、毀損暗紅框。提示框寫建築表的名稱與分類、狀態、作用（城牆、城門另寫城防）。
- 住宅與農田也有卡片（住宅、大型住宅、毀損的住宅、正在蓋的那一棟；附近已開墾的農田），但不佔建築格。

## 3｜聚落詳情的「領地」分頁

- 縮圖（同樣鋪滿）、「打開領地」按鈕、領地資訊、縮小的卡片（一排約三張；完好的卡片省略「完成」兩字）。

## 4｜驗收

- 冒煙：最大的聚落打開「領地」分頁與大圖，卡片涵蓋每一棟建築（分頁、大圖各算一次），全程不改世界；摘要多印 `Cards=`。
- 截圖：`8_holding_big`、`9_holding_village` 改截整個視窗頁（插圖＋資訊＋卡片），放大圖是卡片區左上角的原尺寸。
