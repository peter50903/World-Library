# 08-7a｜知識樹規則（合併《文明帝國》《世紀帝國》《十字軍之王》的做法；分支章節）

> 使用者 2026-10-23：知識技能樹參考《文明帝國》《世紀帝國》《十字軍之王》的內容與做法，調整、合併成我們自己的知識樹。
> 本章修正第 08-6 章的知識樹部分（a、d、e 節的技術、門檻與前置）；時代、聚落等級、餓死與開墾不變。
> 節點清單見 08-7b。數值一律【TEMP】由 Claude 定；★ 為需使用者確認的概念。

## 1｜三款遊戲各取什麼

只取「機制」，不搬名稱、說明文字或數值；技術名稱一律用現實工藝概念，並以正式設定 10A–10N 為主體。

| 來源 | 原作做法 | 我們取用的部分 |
|---|---|---|
| 文明帝國 | 科技樹＋市政樹兩棵樹；靈光一現（做過相關的事，研究直接推進約四成）；時代分期 | 工藝樹（10A–10N）＋**社會制度、信仰文化兩個新領域**；**實踐加速**（10A–10N 已有 PracticeBoostCondition，正式接上） |
| 世紀帝國 | 升時代要先蓋前一時代的特定建築；科技掛在建築上；同一產業的階梯式升級（採集、伐木、鍛造各三級） | **等級閘門**：高階技術要聚落達到相應等級；**技術要有應用場所**（10A–10N 的 ApplicationFacilityIDs）；**同產業階梯效果**（例：基礎鍛造的工具加成，熱處理再加一級） |
| 十字軍之王 | 革新屬於文化、自動緩慢累積；鄰近已知者會讓機率大增；文化領袖的學識加速；地區限定革新；半數革新到手才能進下一時代 | **自動累積、不選題**；**鄰近傳播**（勢力範圍內已知的聚落越多越快）；**專家與學者加速**；**地區條件**（要有森林才研究木工、要有水才研究造船）；**時代是全世界共用**（沿用第 08-6 章，不採各文化各自分期） |

## 2｜我們的規則

**取得（自動累積，不選題、不擲骰）**
- 每個聚落對每項「可研究」技術各自累積研究進度；滿門檻就習得，記正式世界史。
- 每週進度＝該產業從業者人數×1＋專家（代表人物）×5＋學者×10＋鄰近傳播【TEMP】。
- 門檻＝ResearchTimeBase × 325【TEMP】（基礎作物栽培 80 → 26000，與第 08-6 章 a 節相同）。
- 研究資源（ResearchResourceCost）要真的消耗（世界法則第 3 條）；目前世界只有糧食，非糧食資源出現前只計時間。

**可研究的條件（四道閘門，全部滿足才累積）**
1. 前置：ParentTechIDs 全部已習得（跨領域先修照 10P）。
2. 等級：技術階級 1＝任何聚落；2＝村莊；3＝城邦；4＝城市；5＝首都【TEMP】（世紀帝國的升時代閘門）。
3. 地區：該產業真的存在——有從業者，且地理條件成立（森林、水域、礦脈、牧群…，見 08-7b 每列的「從業者」）。
4. 場所：ApplicationFacilityIDs 有列建築時，要有該建築（建築系統出現前，第 1～2 階暫不要求）。

**加速**
- 實踐加速（文明帝國）：PracticeBoostCondition 第一次在聚落真實發生時，該技術立刻推進門檻的 PracticeBoostEffect（例：研究時間－20%＝進度＋20%）。每聚落每技術一次。
- 鄰近傳播（十字軍之王）：勢力範圍內（第 04-1 章：採集範圍；之後國家領土、商路）每有一個已習得的聚落，每週＋門檻的 0.05%，最多 0.25%【TEMP】。
- 遷入與婚嫁：已習得聚落遷入的人，每人帶來門檻的 25%（第 08-6 章 a 節，照用）；專家本人遷入時直接習得。

**持有、效果與失傳**
- 聚落知道≠每個人都會（10P）：習得後補任該技術的專家（代表人物）；專家才是正式持有者。
- 效果三類：解鎖職位（專家、市長…）、解鎖行動或建築（開墾、城牆…）、產業加成（工具＋25%…）。沒有對應系統的技術只記「已知」，不產生效果。
- 失傳（10P、48D）：聚落成為遺跡，且勢力範圍內沒有其他持有者時，該聚落的知識失傳，記世界史；後人可重新研究，遺跡日後可提供古書線索（第 13 章）。

**時代（沿用第 08-6 章，全世界共用）**
- 希望時代：開局五項知識（使用者裁決，見 08-7b 第 1 節）。
- 開拓時代：任一聚落習得開局知識以外的第一項技術。
- 征服時代：第一個王國成立（社會制度「王權」＋首都等級）。

## 3｜與目前程式的差異（下一節實作時修正）

| 目前（第 08-6 章） | 改為 |
|---|---|
| 技術是程式列舉（農耕、木工、鍛造） | 改讀正式設定 10A–10N＋新領域，以 TechID 識別 |
| 木工門檻 39000、鍛造 52000 | 依 ResearchTimeBase×325：基礎木工 32500、基礎鍛造 58500 |
| 鍛造前置＝木工 | 照 10C：探礦→高溫冶煉→基礎鍛造（要有礦脈；地圖尚無礦脈前不會出現鍛造） |
| 工具加成＋25% 掛在鍛造 | 工具階梯：石器改良＋10%（開拓時代第 1 階即可研究）→ 基礎鍛造再＋15% → 熱處理再＋10%（見 08-7b） |
| 只看成年人數 | 加上專家、學者與鄰近傳播 |

## 4｜實作順序

1. 知識樹資料化：讀 10A–10N 與新領域分頁，TechID 取代列舉；門檻公式；存檔改版。
2. 四道閘門與從業者條件；專家依技術補任（代表人物職位由技術表決定）。
3. 鄰近傳播與實踐加速（先接得到的條件：第一次收成、第一次開墾、第一次遷徙抵達等）。
4. 社會制度領域：市長、商會、公會 → 城邦等級。
5. 信仰文化領域：祭祀、巫祝 → 開拓時代的基礎文化與信仰。
6. 城市、首都、王權 → 征服時代。
