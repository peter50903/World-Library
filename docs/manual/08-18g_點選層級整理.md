## 1｜三層，先點到的先算（各種地圖模式、各種遠近都一樣）

| 順序 | 層 | 點到什麼 | 打開 |
|---|---|---|---|
| ① | 角色 | 近景的領袖、工作團體、遷徙隊伍、怪物 | 各自的詳情 |
| | | 遠看的棋子：居民棋 | 聚落 |
| | | 遠看的棋子：職業棋 | 工作團體 |
| | | 遠看的棋子：遷徙棋 | 隊伍 |
| ② | 聚落 | 聚落所在的格；近景再加建築與廣場 | 聚落 |
| ③ | 區域（空地） | 地形模式 | 地塊 |
| | | 勢力模式 | 勢力：最上層聚落，直接翻到「勢力」頁 |
| | | 文化模式 | 文化 |
| | | 信仰模式 | 信仰 |
| | | 糧食、家系、知識模式 | 所屬聚落 |
| | | 怪物佔據的格（地形、勢力模式） | 地下城 |

- 點了之後，選到的東西移到畫面中央並框起來。

## 2｜往上一層

詳情標題下面有一列「↑」連結，不必回到地圖就能往上看：

| 目前打開的 | 往上一層 |
|---|---|
| 地塊 | 所屬聚落、勢力、文化、信仰 |
| 聚落 | 勢力（最上層）、主要文化、主要信仰 |
| 工作團體 | 所屬聚落 |
| 遷徙隊伍 | 出發地、目的地 |
| 文化頁、信仰頁 | 照舊用「返回」 |

## 3｜角色點得到

- 原因：小人只有十幾個螢幕像素，又一直在走，點選範圍等於圖的大小時幾乎點不到。
- 做法：
  - 點選範圍至少 22×30 像素【TEMP】，範圍重疊時選離中心最近的。
  - 每次重畫地圖時重新登記這一幀畫出來的角色。
  - 遠看的棋子也登記成角色。
