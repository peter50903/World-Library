# 08-49｜戰爭平衡：守方也守得住（分支章節）

> 大地圖一百年驗證（08-48 的「海與戰爭」）：55 場征服戰爭，征服 45、議和割讓 6、敗退 0、白和平 0——攻方幾乎必勝。
> 原因：會戰分數最多扣到 −40（08-22a），敗退門檻 −60 永遠到不了；加上 08-47 的圍城糧盡，攻方遲早攻得下。
> 修改：08-22a（敗退）、08-45（野戰）。存檔第 104 版（規則改變）。

## 1｜野戰潰敗【TEMP】

- 野戰的下一週，攻方死傷達守方的 150% 以上＝大軍潰敗，撤兵回國（戰爭結束，算敗退；雙方照常停戰）。
- 史書與戰爭總覽寫「某某的大軍在野戰中被某某的守軍擊潰，撤兵回國」。

## 2｜兵力不支撤兵【TEMP】

- 打仗途中，攻方勢力的兵力掉到守方勢力（含本土加成 125%）的 70% 以下就撤兵（戰爭結束，算敗退）。
- 宣戰要兵力 120% 以上，所以剛開戰不會馬上撤；是打久了、死傷多了、或守方的臣屬長大了才撤。
