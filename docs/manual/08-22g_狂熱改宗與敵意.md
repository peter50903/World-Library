# 08-22g｜信仰的狂熱、改宗與敵意（分支章節）

> 參考 CK3 的宗教（08-22 第 2 節第 4 項的其餘三件；異端分裂見 08-22d）。
> 修改：08-8 B3（原本只有無信仰者會改信）、08-22d（分裂機率依狂熱度）、08-19b 第 2 節（忠誠度的信仰一項）、08-19e（聖戰的加成）。

## 1｜狂熱度【TEMP】

每個還有信徒的信仰有狂熱度（0～100，由現況算、不另存）：

| 因素 | 數值 |
|---|---|
| 基本 | +40 |
| 聖地在手（創立聚落還有人住、主要信仰還是它） | +30；失去聖地 −20 |
| 每個以它為主要信仰的聚落 | +2（最多 +30） |
| 每個還有信徒、從它分裂出去的異端 | −15 |

- 狂熱度低的信仰容易分裂出異端：08-22d 的每年 6% 乘以（150−狂熱度）%——狂熱度 100 是 3%、50 是 6%、0 是 9%。
- 改宗時，上級信仰的狂熱度比自己高越多，改得越快（見第 2 節）。

## 2｜改宗【TEMP】

- 聚落的直屬上級（上週結束時的隸屬）主要信仰和自己不同時，每週有 0.3% 的人（其他信仰的信徒與無信仰者）改信上級的信仰，
  再乘以（100＋上級信仰的狂熱度−自己信仰的狂熱度）%，限 20～200%。大約十年左右，被征服的聚落多數人就改信了上級的信仰。
- 主要信仰因此換成上級的信仰時記新事件「改宗」（各地大事；聚落小史、信仰頁的歷史）：「多數人改信上級某某的『某某信仰』（原本信『某某』）」。
- 代表人物的信仰不變（之後換人時依聚落的信仰比例抽）。

## 3｜敵意【TEMP】

- 兩個信仰：同一個＝無；**同源**（追到最早的母信仰是同一個——異端與母信仰、同一個母信仰的兩個異端）＝**誤入歧途**；不同源＝**敵對**。
- 下級與上級信仰不同的忠誠扣分：敵對照舊 −15（「信仰不同」）；誤入歧途只扣 8（「信仰誤入歧途」）。
- 聖戰的宣戰加成（08-19e 的 +15%）：敵對全額；誤入歧途一半（+7%）。

## 4｜畫面

- 信仰頁：狂熱度與明細、「由某某分裂出來的異端」、與其他信仰的關係（誤入歧途／敵對）；歷史多列異端分裂與改宗。
- 事件清單的篩選選單：原本大部分類別顯示「未知」，改用正式事件類型的名稱。

存檔第 85 版：信仰多一欄「母信仰」（異端記下從哪個信仰分裂）；新事件「改宗」。
