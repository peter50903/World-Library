# 09-1c｜緊湊聚落（分支章節）

> 使用者 2026-11-16：
> - 城市規劃看起來很鬆散，該有的都有，但佔了太多不必要的空間。
> - 強制要求：搜尋、分析 2D 遊戲城市的做法，做出腹地建築緊湊、但看得出是城市、村莊的聚集地。
> - 除了巨大世界，其他大小都放不下這麼多建築；強制參考 CK3 的地圖顯示方式。
>
> 只改畫面與聚落規劃，存檔不改版。

## 1｜參考

| 來源 | 做法 | 採用 |
|---|---|---|
| CK3 地圖（開發日誌 #2、#25、#177；地圖模組 wiki） | 聚落不照比例：每個男爵領一個據點模型，擺在定位點上，依等級換模型、可調大小；一個郡 2～5 個男爵領 | 住屋數依等級設上限（象徵性），人口再多也不再往外攤 |
| Watabou 中世紀城市產生器 | 街區切成窄而深的地塊、建築貼滿地塊；城區之間的密度漸變 | 臨街連排、地塊窄而深；內圈連棟、外圈獨棟 |
| Battle Brothers 戰略地圖 | 城鎮是一團緊湊的建築；農田、磨坊等附屬地點掛在外圍 | 田照舊在牆外一圈，牆內只放建築與街 |
| 中世紀城鎮的街屋地塊（burgage plot） | 臨街窄面、背後一小塊院子，相鄰的牆貼在一起 | 街距縮成「街 1＋房子 5＋後院 1」 |

## 2｜改了什麼

| 項目 | 以前 | 現在 |
|---|---|---|
| 街距（方格） | 13（房子 6＋後院 6） | **7**（房子 5＋後院 1） |
| 房子之間 | 1～2 格 | **0**（連排）；外圍兩成留一格小巷 |
| 規劃半徑 | 44 | **26** |
| 別的聚落中心保留 | 12 | 10 |
| 圍牆多擴 | 4 | 2 |
| 住屋數上限 | 220 | 村莊 14、城鎮 28、城市 44、首都 60 |
| 南北擴張速度 | 往東西長得比南北快 1.5 倍 | 1.1 倍，聚落接近方形 |

- **城市與村莊分得出來**：
  - 村莊：隔一塊地蓋一棟，屋後一列菜畦，偶爾有稻草人；農舍旁的空地種兩棵果樹；泥土路、沒有牆。
  - 城鎮：空地補滿成連排的房子，屋後是院子；木柵。
  - 城市：內圈四成是**連棟街屋**（第十一批 row 素材，相鄰的接成一整排：左端、中段、右端），往外石屋、房子；石牆。
  - 首都：內圈五成連棟、接著磚屋、外圈石屋。
- **比街距高的建築**（神殿 10、主堡 12、會所 7…）可以跨過後面那條街，那一段街不鋪；不能壓到主街。
- **工期**：連棟街屋 10 週。
