# 06-3｜丘陵與礦脈（分支章節）

> 修改：丘陵圖塊重新套用六角形遮罩（08-13 第 1 節）。

> 08-9 工作清單 D1；08-10a V3 b 的地形部分。圖塊素材 `TILE_HILLS`、`OVERLAY_ORE_VEIN` 已交付。數值一律【TEMP】。

## 1｜生成

- 地圖其他地形（陸地平滑、南緣海洋、河流與淺灘）照 06-2 不變；最後一步加丘陵帶。
- 每 8 欄一條丘陵帶（至少一條）：從隨機一格陸地出發，往隨機相鄰的草原或森林格走 4～7 步，走過的格成為丘陵。
- 每個丘陵格 1/3 有礦脈。
- 抽樣用地理流的實體局部亂數，不推進地理流計數器：丘陵以外的地形與開局聚落位置不因此改變。

## 2｜規則

| 項目 | 丘陵 |
|---|---|
| 居住、開拓、遷徙 | 與草原、森林相同（陸地） |
| 採集 | 野採來源（與草原同類），每週供應為草原的一半 |
| 農田 | 不能開墾（只有草原能開墾） |
| 礦脈 | 只記在地圖上、點格顯示；採礦與石材（D2）接上前沒有效果 |

## 3｜知識的地理條件（08-9 D2；修正 08-7b 第 3 節）

| 領域 | 從業者 |
|---|---|
| 10C 採礦冶金 | 聚落 2 格內有礦脈時＝成年人 |
| 10M 珠寶精工 | 同上（寶石尚無） |
| 10D 石造 | 本格或相鄰格有丘陵（石材）時＝成年人 |

探礦→高溫冶煉→基礎鍛造因此重新接得上：習得基礎鍛造的聚落補任鐵匠、工具階梯第二級（08-6 e 節）生效。
礦石與石材的產量、存量、交易留給建築與經濟章節。
