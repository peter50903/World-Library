# 08-21｜CK3 式政治地圖（分支章節）

> 本章修正 08-16「地圖是 WorldBox」與 08-17、08-18b、08-20e 的地圖畫法：正式地圖改成十字軍之王（CK3）式的政治地圖。
> 舊的像素地圖（建築、小人、色塊檢視）暫時留在開發工具「舊地圖」，之後確定不再需要時移除。

## 1｜為什麼改

使用者 2026-11-17 試玩回饋：史書排版沒有重點、巨大地圖很卡、村莊密密麻麻混在一起看不出重點、地下城怪物沒有威脅感；
「這個遊戲的視覺非常糟糕，我現在想要往 CK3 的那種地圖世界開發，不要再走 WorldBox 的路線了」。
Claude 實際操作 CK3 觀察：遠看是低飽和的勢力色塊、勢力邊界深色加內側亮帶、沿勢力長軸排開的大字國名、藍灰海；
中距離出現地形與省界；拉近才有聚落徽章與深藍金邊的名牌。重點靠「勢力」與「名字」，不是一個個房子。

## 2｜省份（Core `DemoProvinceMap`）

1. 每格陸地屬於一個省份＝一個聚落：先照勢力範圍（08-19a，聚落實際用到的地，固定屬於它），再從聚落往外長，
   最遠【TEMP】營地 2.5 格、村莊 3.5、城鎮 4.5、城市 5.5、首都 6.5（代價：直走 10、斜走 14、丘陵 +6、森林 +3、河流 +12；同代價先給編號小的）。
2. 長不到的陸地是荒野（不填色）；海、湖不屬於任何省份；怪物地盤（12-2a）不屬於任何省份，另記是哪個地下城的。
3. 河流在政治地圖上是陸地上的細線（不是一格寬的水），可以跨，但代價高，省界常沿著河。
4. 純函式、不存檔、不影響模擬，只供畫面與點選。

## 3｜畫法

1. 著色器畫底圖：每個像素換成格座標（加雜訊扭曲，邊界不是方格），取四格加權，權重最大的省份就是這裡的省份；
   最大與次大的差距換算成離邊界幾像素，畫省界（細、半透明）與勢力界（粗、填色加深）＋勢力界內側亮帶。
2. 地形依四格混色，再以雜訊畫森林樹冠、丘陵起伏、草地深淺；海有深淺、近岸淺色、海岸深色細線；地圖外是更深的海。
3. 怪物地盤塗暗紅斜紋；選到的省份或勢力整片提亮、金色邊會閃。
4. 三層【TEMP】：遠看（每格不到 30 像素）勢力名＋大勢力的首都徽章；中距離（30～60）城鎮以上的徽章與名牌、小村只畫點；
   拉近（60 以上）每個聚落都有名牌、勢力名淡出、填色變淡露出地形。名牌互相擋到時，首都、層級高、人口多的優先。
5. 勢力名：主軸＝各格位置的主成分方向（偏圓取水平、偏直由上往下），中心＝離邊界最遠的格，沿主軸量到邊界、字平均排開；
   字級 11～72 像素。文化、信仰模式改寫文化名、信仰名。字型：Noto Serif CJK TC Bold 只取地名用字的子集（OFL，`godot/assets/fonts/`），缺字退回系統字型。
6. 聚落徽章：深藍圓底金邊，中間依層級畫帳篷、房子、塔、城堡；勢力首都（兩個省份以上）頭上一頂王冠。
7. 怪物巢穴：暗紅圓底骷髏，遠看寫隻數、拉近寫「名字　怪物 N（L 級）」；沉寂的地下城拉近才畫灰色。
8. 戰線、交戰沿用 08-18m（佔領斜紋、行軍路線、軍旗、比分條）。

## 4｜地圖模式與點選

1. 預設＝勢力模式（政治地圖，新世界一開始看整個世界）。地形模式＝細節地圖（不塗勢力色、只留邊界）。
   文化、信仰、家系、知識照各自的顏色塗省份，同一組之間不畫粗界。
2. 點選規則照 05-1／08-18g：名牌與徽章開聚落；點陸地第一下照模式（勢力模式選到勢力，整個勢力金邊），同一格再點換到地塊、聚落。
   政治地圖每格陸地都有省份，所以點荒野以外的地方都選得到。滑鼠提示寫出省份的聚落、勢力、地形與怪物。
3. 操作：滾輪縮放（最大每格半徑 64）、中鍵或右鍵拖曳移動、「全世界」一鍵看全圖。

## 5｜驗證

1. Core 測試 `DemoProvinceMapTests`：聚落格與用到的地屬於自己、省份在距離內、水與怪物地盤不屬於任何省份、荒野、遺跡、結果固定。
2. CI 無畫面冒煙 `WORLD_SIM_POLITICAL_SMOKE`：省份、勢力、勢力名、聚落格點得到自己的省份、點陸地選到勢力、滑鼠提示。
   既有的冒煙測試照舊用舊地圖的地形模式（點選與座標規則不變）。
3. CI 截圖：PR 貼「map-shot」標籤時以 xvfb 開真的畫面，大地圖跑 30 年，拍整個世界、中距離、近距離、地形模式、文化模式五張，存成 artifact。
4. 使用者確認：開新世界（大或巨大地圖），快轉幾十年，拉遠拉近看勢力、名字與名牌；切換地圖模式；點勢力、點名牌。

## 6｜之後（依序，各自開章）

1. 巨大地圖效能：每週刷新不再整理全部歷史事件（右側清單只取最近的）。
2. 史書排版：章節標題、要事放前面、名稱可點。
3. 怪物威脅：地盤擴張與襲擊在地圖上看得到、規則再調。
4. 參考 CK3 的宗教（教義、聖地、異端）、性格與身體特質、戰鬥（軍隊、指揮官、圍城）、宣戰理由與戰爭進行方式（戰爭分數、佔領、停戰）。
