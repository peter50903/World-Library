# 08-37｜建築的作用（分支章節）

> 使用者 2026-11-18「直接做正式建築系統」、核心原則「文明發展」與「人類與怪物爭奪領土」。08-32 的建築第一版只記錄建築，08-34 讓城牆有作用、08-36 讓等級看真的建築；
> 本章讓**其他建築也有作用**（參考 CK3 的建築加成，依 18D 建築活動簡化），領地面板寫出每棟建築做什麼。
> 修改：08-32（施工、採集、備料）、08-34（城防多了城堡）。存檔改第 98 版（規則改變）。

## 1｜作用

只算**完好**的建築（施工中、毀損的沒有作用）；同一種蓋好幾座只算一次。看上一週的建築（本週蓋好的下週才生效），不存檔（由建築算出）。

| 建築 | 作用 |
|---|---|
| 抄寫室、學校、高等學院、魔法學院 | 研究 +10%、+15%、+25%、+10%（相加，乘在領袖的倍率上） |
| 糧倉 | 每週的存糧腐敗少 50% |
| 工坊 | 施工工時 +20% |
| 木材場、採石場、礦場 | 採木、採石、採鐵的工時減半 |
| 倉庫 | 閒時備料的上限加倍 |
| 兵營、靶場、馬廄 | 士兵 +20%、+10%、+10%（駐軍與討伐軍；鎮以上才有士兵；不超過成年人） |
| 診療所、醫院 | 怪物（襲擊、獸潮）害死的人少 15%、30%（取高者；至少還是死 1 人；全村覆滅不算） |
| 城堡 | 怪物來襲時守方戰力 +20%、大軍圍城多 2 週、攻城死傷 −15%（沒有城牆也算；併入 08-34 的城防） |

其他建築（農舍、市場、旅店、神殿、市政廳、港口……）的作用之後的章節再做（市場、農田加成牽動貿易與來源加成，另外處理）。

## 2｜看得到的地方

- 領地分頁與大圖列表：多一段「**建築加成**」（相加後：研究 +25%、存糧腐敗 −50%……，每項有分類圖示）；完好的建築那一列後面寫作用（「學校：完成｜研究 +15%」），提示框也寫。
- 聚落現況多一行「建築加成：…」；城防那一行有城堡時寫「城防（城堡、石牆）：…」。

## 3｜驗收

- 測試：只有完好的建築有作用、同一種只算一次、醫院與診療所取高者、文字；城堡（沒有城牆也算）；兵營讓士兵變多（村莊沒有駐軍）；工坊、木材場、採石場讓鐵匠鋪蓋得比較快；同一串運氣下醫院讓怪物害死的人變少；中地圖有糧倉的聚落那一週腐敗少一半、其他照舊，現況看得到。
- 平衡（`balance` 標籤）：看一百年的人口、怪物害死、鎮／城／都／國與第 08-36 章比較。

> 狀態：完成（待實測）。
