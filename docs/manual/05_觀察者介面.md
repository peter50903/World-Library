## 1｜設計方向

只參考上述遊戲的**版面配置與操作習慣**，不複製其美術、圖示、字型或任何素材。

- **地圖永遠全螢幕**，是畫面主角；所有介面都是疊在地圖上的面板，可收合，不另開作業系統視窗。
- **頂部資訊列**（十字軍之王 3 式）：左側世界名稱與配方摘要；中間全世界人口、糧食、聚落數、本週出生／死亡；右側日期「第 Y 年 M 月 D 日」。
- **右下時間控制**（十字軍之王 3 式）：暫停鍵＋速度 1～5 檔（對應既有每秒 1／5／30 天等 TEMP 速度，檔位數值為 TEMP 顯示參數）；空白鍵切換暫停、數字鍵 1～5 切換速度。
- **左側詳情面板**（點選才開）：點六角格或聚落時從左側滑出，顯示 Core 點格查詢的內容（地形、來源、聚落、人口、糧食、遷徙隊伍）；可固定、可關閉；點地圖空白處或按 Esc 關閉。
- **右側關注清單**（十字軍之王 3 的大綱清單式，可收合）：聚落列表（名稱、人口、糧食狀態），點一下地圖置中並開左側詳情。
- **底部事件列**（Fantasy Map Simulator 的世界紀錄式）：最新事件捲動顯示，點事件開事件詳情並定位地圖；重大事件以醒目色標示並觸發自動暫停（沿用既有開關）。
- **地圖模式切換**（十字軍之王 3／Fantasy Map Simulator 式，左下小按鈕列）：地形（預設）、人口密度、糧食狀況（充足／緊張／飢餓）、共享來源範圍。本章先做地形與糧食狀況兩種，其餘模式隨後續章節加入。
- **底部工具列**（WorldBox 式圖示按鈕列，置中）：情境與新世界、存讀檔、年度圖表（第 08 章）、說明。每個按鈕開一個置中的疊加視窗（modal），不是作業系統視窗。
- 面板與按鈕外觀等素材交付前，用 Godot 內建樣式＋羊皮紙色系的純色 `StyleBox` 頂替。

## 2｜規則

- 所有數字與文字來自 Core 的同一次讀取；Godot 不自行計算世界、不改世界（點格、切模式、開關面板前後 `StateFingerprint` 相同）。
- 版面數值（面板寬度、邊距、速度檔位、字體倍率）都是 TEMP 顯示參數，集中在單一常數檔並標 `TEMP`，不進設定檔。
- 畫面縮放：視窗任意大小（含未最大化、1280×720 到 3840×2160）時，面板都完整在視窗內、可見、不互相重疊遮住頂部列與時間控制。
- 玩家可見文字繁體中文；快捷鍵在說明視窗列出。
- 冒煙必須真的會失敗，不接受恆真斷言。
