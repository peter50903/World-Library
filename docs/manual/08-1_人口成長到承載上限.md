# 08-1｜人口成長到承載上限（第 08 章分支章節）

> 修正第 08 章「普通世界大多走向滅絕」。效力：總綱 ＞ 本章 ＞ 第 08 章。使用者 2026-10-21 給定目標，程式與數值由 Claude 決定。

## 目標（使用者概念，已定案）

普通世界（人類採集）應呈現：採集補充食物 → 生育增加人口 → 人口過多、糧食不足時遷移建村 → 反覆擴散，直到人口接近**地圖理論可供養上限** → 之後大致維持在上限附近（目前沒有戰爭、災害，只有老死與飢荒死亡）。

## 規則修正（Claude 定案，皆【TEMP】）

1. **宜居開局**：自然採集世界的開局聚落只放在可取水的陸地（聚落格相鄰有水域）。舊情境位置不變。理由：沒水的開局聚落第一週就因缺水累積生存債而餓死。
2. **開拓需要一對伴侶**：開拓隊的第一戶必須是一對成年伴侶，放不下任何一對就不出發。理由：1～6 人、沒有伴侶的開拓隊建立的聚落無法繁衍。
3. **擇偶依年齡**：育齡女性先配對，各自配給同聚落、未配對、非近親、年齡最接近的成年男性。理由：舊規則「ID 最小的男性」常讓老人占走年輕伴侶。
4. 存檔第 16 版（規則改變，舊存檔一律「版本太舊」）。

## 承載上限

- `DemoMapCapacity`：可及自然來源（至少一個可取水陸地格可及）每週供應合計 ÷ 成人每人每週食量＝理論上限人數（成人當量，TEMP 估計）。
- CLI 普通世界長期生存調查與年度圖表都對照這條上限。

## 驗收

- 調查種子 1～20 各跑 100 年：多數種子人口在期內逼近上限，並在最後 20 年維持在上限附近區間（門檻見下方狀態，TEMP 登記於 `docs/TEMP_待裁決清單.md`）。
- 不得只為單一種子好看而調數值；每項改動都要能說出是哪個死因。
- 第 08 章 M1 正式驗收仍須通過。
