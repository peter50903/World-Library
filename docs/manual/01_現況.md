## 1｜玩家現在能玩到什麼

Godot 4.7.2 .NET 開 `godot/project.godot` 按 F5：
- 12×8 尖頂六角格 TEMP 小世界（草原、森林、水域、主河道），純色繪製，尚無美術圖。
- 預設情境「人類繁衍＋自然死亡」：只用人類；自然地塊每週共享供糧（森林 20、草原野採 8、主河道 5、一般水域 3，每來源一份，接壤聚落共用）；成年雙親受孕、39 週 TEMP 孕期、出生、年齡相關自然死亡、飢餓死亡；嬰兒吃糧但不算勞力。
- 其他 TEMP 情境：一般、全面饑荒、局部饑荒、開拓、森林河流採集、人口過密；切換須確認。
- 操作：滾輪縮放、中鍵拖曳、點格查詢、▶播放／⏸暫停、每日／30 日快轉、事件列表與事件詳情（直接原因／後果可點、地圖定位）、重大事件自動暫停提示、3 個 TEMP 存檔槽。
- 獨立「世界控制台」視窗（情境、播放、糧食週帳、存檔槽）；Windows 11 未最大化時看不到，將由第 05 章改為全螢幕地圖＋疊加面板。
- 日期顯示「第 Y 年 M 月 D 日」，曆法由 Core 依 `01_世界參數` 計算。
- CLI：`dotnet run --project src/WorldSimulation.ObserverCli -- --demo --seed 42 --years 100` 跑無畫面長測；互動指令 `save N`／`load N`／`slots`、`--m1-check` 產生 M1 TEMP 驗收報告。

## 4｜已知缺陷（依嚴重度）

1. 人口亂數自製雜湊，違反亂數架構（第 04 章 a 節修）。
2. 「人類繁衍」情境禁止遷徙，人口過多只能餓死（第 07 章）。
3. 共享供糧採貪婪分配，會造成可避免的餓死（第 06 章；裁決：依成年勞力比例分配）。
4. 舊情境與 M1 驗收仍有「草原自動農田 30」免費產糧，違反規則（第 08 章退場）。
5. 控制台視窗在 Windows 11 未最大化時看不到（使用者 2026-10-15 實測；第 05 章改版取代）。
6. ~~讀檔不重算週結算；共享採收沒有來源層級帳~~：第 04 章 b 節加選用完整驗證（重跑比對）、c 節加來源層級帳（待合併）。
