# 08-10h｜更多性格：八組十六項（分支章節）

> 修正 08-10g 第 3 節（三組六項、每人兩項）。存檔改第 66 版（規則改變）。
> 使用者 2026-11-17：性格特性希望可以多一點。

## 1｜規則

- 八組相反的性格，每位領袖在其中三組【TEMP】各有一個（十字軍之王的角色也是三項個性特質）。
- 子女 50%【TEMP】承襲父母的一項：自己抽到同一組的那一項換成父母的；沒有同組的就換掉最後一項。
- 效果（全部【TEMP】）。「上級領袖」＝王座所在聚落的領袖。

| 組 | 性格 | 效果 |
|---|---|---|
| 1 | 好戰 | 每次檢查宣戰的機率 +20% |
| 1 | 謹慎 | 兵力要達對方 200% 才宣戰（原本 120%） |
| 2 | 寬厚 | 下級請願成功率 +25% |
| 2 | 嚴苛 | 下級請願成功率 −25% |
| 3 | 公正 | 下級忠誠 +10 |
| 3 | 暴虐 | 下級忠誠 −10 |
| 4 | 野心 | 自己是下級時，對上級的忠誠 −15 |
| 4 | 知足 | 自己是下級時，對上級的忠誠 +15 |
| 5 | 勇猛 | 交戰時對方的死亡 ×125% |
| 5 | 怯懦 | 交戰時對方的死亡 ×75% |
| 6 | 堅毅 | 對方兵力達 10 倍才不戰而降（原本 5 倍） |
| 6 | 軟弱 | 對方兵力達 3 倍就不戰而降 |
| 7 | 狡詐 | 不理會停戰照樣宣戰；下級忠誠 −5 |
| 7 | 守信 | 下級忠誠 +5 |
| 8 | 虔誠 | 聖戰的宣戰加成 ×2；信仰不同的下級忠誠再 −10 |
| 8 | 多疑 | 不為信仰開戰；不計下級「信仰不同」的忠誠扣分 |

- 忠誠的每一項都列在聚落詳情的忠誠明細（領袖公正、領袖暴虐、領袖守信、領袖狡詐、本地領袖有野心、本地領袖知足、領袖虔誠容不下異教）。
- 交戰的死傷看帶兵一方的領袖：獨立戰爭是叛軍首領聚落的領袖與上級領袖；征服戰爭是雙方勢力的上級領袖。

## 2｜玩家看到

- 人物頁「性格」底下，每一項性格多一行說明（例：「好戰：更常向鄰居宣戰」）。
- 史書的人物句照舊列出性格。

## 3｜還沒做（要接到別的系統）

- 好學／守舊（研究速度）、慷慨／貪婪（糧稅率）、仁心／冷酷（饑荒時開倉）：要改知識與週結算，另開工作。
- 領袖以外的人物（農師、學者…）的性格。
- 事件改變性格（十字軍之王的人生事件）。
