# 08-48｜文字對比檢查與大地圖驗證（分支章節）

> 使用者 2026-11-25：「幫我確認遊戲的文字跟底圖顏色要是不一樣的，不然會有難以辨識的問題」；並照規劃先做大地圖百年驗證。
> 08-47 的戰爭視窗曾把金色字放在羊皮紙底上，完全看不見——本章讓這類問題在 CI 就被抓出來。只加檢查與報表，不改規則、存檔不變。

## 1｜文字對比檢查【TEMP】

- 介面冒煙測試時掃過主畫面、聚落詳情的每一個分頁、每一個視窗（領地、戰爭、法則、存讀檔、說明、情境、開發……），
  每個看得到、有字的標籤、按鈕、多行文字都算一次：
  - 底色＝往上找第一個畫得出底的元件（按鈕底、面板、色塊；扁平按鈕與半透明的底再往上找）；羊皮紙、木板等貼圖取平均色。
  - 有描邊的字以描邊色當底。
  - 對比度用 WCAG 公式（1～21），低於 3:1（大字與介面元件的標準）就列出：哪個畫面、哪段字、對比、字色與底色。
- 結果寫成 CI 註記「文字對比」。CI 開著嚴格模式（`WORLD_SIM_CONTRAST_STRICT=1`）：有低於 3:1 的字就讓測試失敗。
- 第一次檢查 308 處有 16 處不足，已修：面板裡的按鈕原本是 Godot 預設的深灰半透明底配深色字（✕、打開領地……）→ 全介面按鈕改淺羊皮紙底、深棕框、深色字；
  技術樹的階級字（Ⅰ、Ⅱ）是深色字配黑色描邊 → 改淺色；年度圖表的「明細」淺灰字在羊皮紙上 → 跟著按鈕改深色；世界法則的開關綠字、紅字加深。
- 地圖上自己畫的字（勢力名、名牌、圍城字樣）都有深色描邊或底板，不在檢查範圍。
