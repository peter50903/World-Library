# 08｜M1 土地開發、年度圖表與 M1 正式驗收

> 本章部分內容已由 08-1 修正（普通世界人口成長到承載上限）。

> 前置：第 07 章。對應舊任務 P1.1.08～P1.1.10，以及提前做的 P1.7.01-a、P1.7.02-a。規格＋切片層級。

## 規則（已定案）

- 農田不是草原自動生成的資源：必須先有真實的開墾狀態，形成可辨識的農田地塊（地表類型與土地開發狀態分離、畫面可辨識）。
- 開墾需要真勞力、材料、時間；依開發程度供糧，上限由**當前持有的農業知識**決定；只有解鎖特定農業知識才能提高上限；時間流逝或人口增加不會自動變農田。
- **M1 驗收不要求農田**；開墾與農田產出在知識系統（第 11 章）之後才啟用。
- **草原開墾為農田後不再提供野採，只產農糧。**
- 舊模型「草原自動農田 30」違反規則，必須退場（舊情境與 M1 驗收工具都要移除）。
- 正式 M1 驗收：普通世界中至少存在由真實資源支撐、長期有人生存的可重現種子／區域，且人口可因合法出生增加；同時保留資源差導致衰退、局部或全面飢荒、開拓的案例；不得為漂亮曲線偷改設定或放寬 CI。

## 切片

### a｜舊自動農田退場與土地開發狀態模型（P1.1.08-a/b）
- 刪除所有「草原自動農田」產糧路徑（`DemoWeeklyTempConfig` 農地 30、舊情境、M1 驗收工具中的引用）。
- Core 新增土地開發狀態（未開發／開墾中／農田＋開發程度），與地形分離；**本章只建模型與畫面辨識，不啟用產糧**（產量上限需知識持有，第 11 章接上）。
- 驗收：所有情境不再有免費農糧；百年長測守恆；受影響情境的種子若失去存活案例，如實記錄，不調數值補回。

> 狀態：完成（2026-10-21，待合併）。程式落點（Claude 定案）：刪除 `FarmlandRegenPerWeek` 與 `DemoResourceKind.Farmland`；所有情境草原資源點一律「未開墾草原」（存量 0、不再生、不產糧，結算略過）。`DemoLandDevelopmentMap`（`Undeveloped`／`Clearing` 1～99%／`Farmland` 1～100%，只限草原、非聚落格）與地形分離；農田從自然來源移除（不野採），開墾中仍可野採【TEMP】；本章不產糧、沒有開墾行動，世界裡永遠為空，存檔 `State.Land` 非空即拒讀；Godot 依狀態貼 `TILE_FARMLAND`／`TILE_FARMLAND_CLEARING`，點格多一行土地開發。存檔第 15 版。受影響紀錄：舊「一般示範」等非共享情境中，只有草原資源點的聚落失去糧食來源、會衰退甚至滅絕（如實保留，不調數值）；有林地／漁場的聚落仍可長期存活；共享採集情境原本就沒有農田，不受影響。

### b｜年度人口圖表、真週報與事件定位（P1.1.09）
- Godot 控制台新增年度圖表：人口、出生、各類死亡、遷入出、糧食採收與缺口；資料全部來自 Core 已提交週報彙整成的年帳。
- 點圖上某年→跳到該年事件；點事件→地圖定位（沿用既有詳情）。
- 驗收：圖表數字與 CLI 年報逐年相同；冒煙比對 Godot 與 Core 年帳。

> 狀態：完成（2026-10-21，待合併）。程式落點（Claude 定案）：Core `DemoYearLedger.FromWeeks` 只從已提交週報彙整年帳（進行中的年份也列出），與 `DemoCenturyRun` 逐年逐欄相同（年帳加腐敗欄、途中出生／自然死亡計入）；CLI 互動指令 `y` 印年報。Godot 底部工具列加「圖表」（`UI_ICON_CHART` 待製作，暫顯示文字）開疊加視窗：四組系列（人口；出生／餓死／自然死亡；遷出／遷入；採收／缺口）長條圖套 `UI_CHART_FRAME`，點長條看該年年報，「看這一年的事件」把世界紀錄篩到該年日期範圍，再點事件沿用既有詳情與地圖定位。工具列 TEMP 寬 260→332。

### c｜不變量註冊表與長測執行器（P1.7.01-a、P1.7.02-a，提前）

- 長測執行器：`--years N --seeds a,b,c`，輸出年度摘要與不變量結果，CI 跑 3 種子 × 100 年。
