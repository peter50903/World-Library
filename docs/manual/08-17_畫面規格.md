# 08-17｜畫面規格：重做畫面層（分支章節）

> 本章第 2～5 節的畫法已由 08-18b 修正（世界改為方格）。

> 修正 08-16 第 11～13 節的地表、田地、建築畫法。模擬核心與規則不動。
> 使用者 2026-11-05：智慧種族被埋沒在地圖裡、田地被切得亂七八糟、城牆透視錯誤，完全沒有 WorldBox 的生動感。決定保留模擬核心、重做畫面層：畫面改用正方形像素格（規則仍是六角格），人用指示物表現（戰略遊戲式：依功能分組，以大小表示人數）。

## 1｜原則

1. **人最顯眼**：地圖上最先看到的是聚落、人群與它們造成的改變，其次才是地形。自然景觀調暗、降飽和；人造物與指示物保持原色，加深色描邊。
2. **一套畫法**：所有物件用同一個透視、同一個光源、同一個像素密度。沒照規格畫的素材不進遊戲。
3. **只改畫面**：畫面上的東西全部由 Core 已有的狀態推得（固定雜湊，不抽世界亂數、不存檔）。讀檔前後畫面相同。

## 2｜畫面格：正方形像素格

- 地表改成一張正方形小格的地圖（以下稱「方格」），每格 8×8 個圖像素。一個六角格大約是 5×6 方格。
- 每個方格屬於中心最近的那個六角格（保留現在的平滑扭曲，海岸、林緣仍是彎的），規則照舊依六角格計算。
- 田地、房屋、道路、城牆全部**對齊方格**。地形的交界可以彎曲，人造物一律方正。

## 3｜透視與光源（WorldBox 式）

- 地面是正上方俯視。
- 立體物件（樹、山、房屋、城牆、指示物）是**俯視略帶正面**：底部佔幾個方格，高度往上長，最多 1.5 方格，看得到正面與屋頂，看不到側面。
- 光源在左上；每個立體物件在右下畫一塊半透明的落地陰影，避免看起來浮在空中。
- **城牆**：上下兩側的牆段畫正面（看得到牆面與垛口）；左右兩側只畫牆頂（一條窄的石帶）；四角與城門各畫一座塔。城牆圍住聚落佔地的外框，對齊方格。

## 4｜田地與聚落版面

- **田地**：一塊農田（規則上的一個六角格）畫成 2～4 塊長方形田區，每塊 3×2 或 4×3 方格。田區之間留一格寬的田埂或小路，相鄰六角格的田沿方格連成大片。作物依季節與開墾進度變化：翻土→播種→綠苗→成熟→收割後的空田。
- **聚落版面**：中心是一塊廣場，主要建築放在廣場邊，住屋沿道路往外排。道路從廣場通往田區、伐木地與礦坑，路網看得出人往哪裡工作。
  - 營地：帳篷圍著火堆，沒有道路。
  - 村莊：木屋、木柵、一兩條土路。
  - 城鎮：石屋、市集廣場、主要道路。
  - 城市：石牆圍住，城門通往主要道路。
- **設施地標**：聚落擁有的設施（井、市集、神殿、鐵匠鋪、磨坊等）畫成對應的建築，放在廣場邊，一眼看得出這座城有什麼。缺素材的設施先用住屋頂替。

## 5｜指示物（人）

使用者 2026-11-05：不畫每一個人，像戰略遊戲用棋子表示部隊——依功能或團體分組，以大小象徵人數。

- **種類**（依功能；由 Core 現有狀態推得）：
  | 指示物 | 出現條件 | 位置 |
  |---|---|---|
  | 居民 | 每個有人聚落一枚 | 廣場 |
  | 農民 | 有農田 | 田區 |
  | 樵夫 | 有進行中的伐木 | 伐木地 |
  | 礦工 | 有進行中的採礦 | 礦坑 |
  | 獵人 | 會狩獵且附近獵物不稀少 | 附近森林 |
  | 漁民 | 臨河或臨海 | 水邊 |
  | 遷徙隊伍、開拓隊 | 途中的隊伍 | 沿路線移動（取代現在的遷徙小人） |
  - 之後有軍隊、商隊時再加種類。
- **外觀**：圓形底座＋職業圖案（鋤頭、斧頭、十字鎬、弓、魚、帳篷…），底座外圈是文化代表色。
- **大小表示人數**（使用者 2026-11-05：級距要大，特大世界的軍隊也要放得下）：每十倍一級，共五級——1～50、51～500、501～5,000、5,001～50,000、50,000 以上；最高一級另加金邊。底座下方一律寫人數（千以上寫「1.2 千」「3.4 萬」）。日後的軍隊、商隊用同一套級距。
- **動作**：工作類的指示物以約 2 秒的週期，在聚落與工作地之間往返（使用者 2026-11-05 確認）。不做逐格尋路，直接沿道路或直線移動。
- **數量上限**：每個聚落最多 6 枚，只畫畫面內的聚落。指示物的位置每秒更新 4 次，與地表烤圖分開，不重烤地表。
- **分層顯示**（08-15；使用者 2026-11-05：視角放大就不顯示）：
  - 戰略層：只有居民指示物，大小即聚落規模。
  - 區域層：加上工作類與遷徙隊伍，工作類來回移動。
  - 近景層：不畫指示物，只看田地、建築與地形本身的細節。

- 城牆：正面牆段、牆頂、角塔、城門，各兩種材質（木柵、石牆）。
- 指示物：圓形底座、職業圖案 8 種、金邊。
- 第四批已交付但不符第 3 節透視的建築與城牆素材停用，檔案保留。

## 7｜施工順序（每步一張 PR，做完先給使用者看）

1. 方格地表與方正田地（不加新素材，先用程式畫的色塊驗證版面）。
2. 聚落版面：廣場、道路、住屋排列、城牆對齊方格。
3. 指示物（先用程式畫的圓形與文字，素材到了再換）。
4. 第五批素材接上畫面。
5. 之後才回到人物頁、設施地標的補完與開鑿水渠。
