## 1｜丘陵不再亂成一團（回饋之 1）

- **山頭**：只長在每 3×3 方格一個的位置，上下錯開一方格。約一半的位置有山頭（大的 18%、小的 32%）【TEMP】，排成一片片山脈，彼此不疊在一起。
- **岩石**：只在一般丘陵上、山頭兩方格以外，2.5%【TEMP】。
- **礦石**：
  - 只在礦脈格中央的 2×2 方格、不在山頭上，一格一兩塊，聚在一起。
  - 開採中的格只剩礦坑。
  - 有素材時，地面不再撒黃色礦點。

## 2｜點選的層級（回饋之 2，照 WorldBox；使用者 2026-11-07 選定）

| 遠近 | 地圖模式 | 點到 |
|---|---|---|
| 拉遠（區域層、戰略層） | 地形、勢力 | 勢力詳情（第 3 節） |
| | 文化 | 文化詳情 |
| | 信仰 | 信仰詳情 |
| | 其他 | 照舊點格 |
| 拉近（近景） | 全部 | 小人或建築（廣場、地塊與上方兩方格）是那個聚落的詳情；其他照舊點格（地下城、森林、礦脈…） |

- 點了之後，鏡頭先把選到的東西移到畫面中央並框起來；點到勢力時移到勢力最上層的聚落。

## 3｜勢力合成一片（回饋之 4）

- 同一個勢力的範圍是一整片顏色，不再畫裡面直屬聚落之間的分界線。
- **名牌**：
  - 拉遠時只標各勢力最上層的名字（例如「瑞文波鎮」），人數是整個勢力的人口。區域層標村莊以上，戰略層標城鎮以上。
  - 拉近時每個聚落標自己的名字，不再寫「屬某某鎮」。
- **勢力詳情**（Core 的 `DemoTerritory.Detail`）：
  - 標題是最上層聚落的名字。
  - 「概況」寫轄下聚落數（含直屬數）、勢力人口、範圍格數。
  - 「隸屬」由上而下列出整棵隸屬樹，每層縮排；同一層依層級高、人口多、編號小排列。

## 4｜野生動物先不畫（回饋之 5）

- 鹿、山羊、狼只是在畫面上遊蕩、沒有實質作用，近景先不畫。模擬裡的獵物與狼照舊（狩獵、野獸攻擊）。
- 地下城的怪物照畫。

## 5｜快轉不卡（回饋之 3）

原因：天災疊層的強度與開墾進度幾乎每 0.25 秒就變一點。每變一次，那一格所在的整塊 512×512 地表就要重烤，每幀最多烤 4 塊，每塊幾十毫秒。觀察者面板每 0.25 秒也整個重算一次，連帶讓地圖的版面、指示物與地表快取一起失效。

- **只有看得出來的變化才重烤**：
  - 天災疊層強度分 12 階，開墾進度分 10 階【TEMP】，跨階時那一格才重烤。
- **重烤得少**：
  - 地表的塊改成 256×256。
  - 一格改變只重烤它與四周零件會碰到的塊。
  - 每幀烤圖最多花 5 毫秒【TEMP】，至少烤一塊，其餘下一幀再烤；還沒烤好的地方照舊顯示舊圖。
- **面板少算一點**：
  - 快轉時面板每 0.5 秒才更新一次【TEMP】。
  - 家系地圖只在聚落改變時才重算。
  - 聚落規模、文化、信仰的內容沒變時沿用同一份資料，讓地圖的各種快取不必重算。
  - 染色素材的快取不再每次組字串。
