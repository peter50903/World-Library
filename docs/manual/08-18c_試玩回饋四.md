## 1｜畫面變乾淨（回饋之 1、2、6）

- **花**：一般草原 1.5%、花原 7% 的方格有花，草叢 12%【TEMP】。
- **動物**：不再一隻一隻畫，而是每 4×4 格一個棲地，依棲地裡的總數挑著畫（第 2 節）。
- **紅色天災警示符號**：地圖上全部不畫（各層都不畫）。天災只看地表的痕跡、會動的物體與編年史。第五批素材的 `mark_disaster` 停用。

## 2｜動物的習性（回饋之 3）

數量仍來自模擬裡每格實際的獵物與狼（第 12-1 章 C1），只決定畫什麼、怎麼動：

| 動物 | 習性 | 條件【TEMP】 |
|---|---|---|
| 鹿（丘陵上是山羊） | **成群**：一起在牧場附近慢慢遊走、一起停下低頭吃草 | 棲地獵物 ≥16 一群 2 頭、≥32 一群 3 頭 |
| 鹿 | **獨行**：一頭在牧場附近遊走 | 棲地獵物 6～15 |
| 狼 | **狼群**：頭狼在前、其他排成一列跟在後面，在巢穴格與隔壁獵物最多的獵場格之間來回巡獵 | 棲地狼 ≥3，一群最多 3 匹 |
| 狼 | **獨狼**：一匹在巢穴附近遊蕩 | 棲地狼 1～2 |
| 地下城怪物 | 在門口來回踱步 | 每個地下城一隻 |

## 3｜透視與地形（回饋之 4、5）

- **不蓋住樹頂**：地表的樹烤在底圖裡，畫在上面的東西一定會蓋住它，所以讓兩者不重疊：
  - 聚落地面（廣場、道路、屋地）上方三方格、左右與下方一方格內不長樹。房子往上長出自己的方格，屋頂不會壓在樹冠上，也不會有樹擋在房子前面。
  - 小人與動物只站在**空地**：本格是陸地，而且本格與下方兩列（左右各一方格）沒有樹與山頭。
- **陸地生物不進水**：
  - 動物只在空地上活動；狼群巡獵的直線路徑一路都要是空地，否則就待在巢穴附近。
  - 小人的家門與目的地都是空地。漁民走到緊鄰水邊的空地，不走進水裡。路上會穿過水或樹林時，改去廣場。

## 4｜名字帶層級（回饋之 9）

- 聚落名字後面加一個層級字：營、村、鎮、城、都（瑞文波營→瑞文波村→瑞文波鎮…）；遺跡是「瑞文波遺跡」。
- 用在地圖名牌、滑鼠提示、聚落詳情的標題、聚落列表。編年史照事件當時的寫法，不回頭改。

## 5｜巨大地圖快轉不卡（回饋之 8）

原因：巨大地圖一次週結算要 70～120 毫秒，原本在主執行緒上算，每隔幾幀畫面就停一下。最快一檔（每秒 365 天，約每秒 52 週）本來就超過電腦一秒算得完的量。

- **背景執行緒推進世界**（08-14 多執行緒的第一步）：畫面照常每幀重畫，世界算完一批才把新狀態交給地圖與面板。地圖拿的都是 Core 的不可變快照，所以背景在算的時候畫地圖是安全的。
  - 背景推進時主執行緒不碰世界：任何滑鼠按鍵或鍵盤輸入都先等這一批算完，最多等一次週結算。所以點格、開詳情、存讀檔、切換情境看到的都是完整的一天。
  - 推進結果與逐日按「下一天」完全相同（同一個世界、同樣逐日呼叫 Core）。
  - 背景一批最多算 250 毫秒【TEMP】，然後先交回畫面。
  - 電腦算不了那麼快時，實際速度會低於選定速度，狀態列寫「實際約每秒 N 天」。
  - CI 冒煙照舊同步推進。
- **地表縮圖切成 256×256 的小塊**：改變時只重新上傳改到的塊（原本每次上傳整張，巨大地圖 14 MB）。
- **自然交界的參差**只重算改變的格與四周一格（原本每次重算全圖 22 萬個方格）。
