# 08-16｜簡化與表現優先（分支章節）

> 使用者 2026-11-03：以參考遊戲來看，系統已接近策略遊戲的數量，但大多只微調糧食、玩家看不出世界在變。
> 決定**兩個都要**：WorldBox 的直觀＋十字軍之王三的深度，一步一步簡化。本章修正 08-7a、08-8、08-9、12-1 的後續方向；效力高於這些章節的未開工部分。

## 1｜總原則

**地圖是 WorldBox，紀錄是十字軍之王。**

- 地圖上只放一眼看得懂的東西：人群移動、聚落長大、火在燒、田被淹、荒地長回來。
- 深度收進編年史與人物頁：想讀故事的人去讀，只看地圖的人也能懂。
- **系統檢查（每個既有與新系統都要過）：它能不能讓地圖上出現看得見的變化，或在編年史留下一段故事？**
  兩樣都做不到的，只留在內部運算，不再往詳情面板、帳本、地圖模式接。

## 2｜既有系統分級（使用者 2026-11-03 確認）

| 系統 | 分級 | 玩家看到什麼 |
|---|---|---|
| 人口、遷徙、聚落五級 | 核心，保留 | 地圖上人群移動、聚落變大 |
| 飢餓債、週帳細節 | 只留內部 | 只看「挨餓」「餓死」 |
| 知識樹 | 收斂顯示 | 時代＋每個時代 3～5 個關鍵技術（世紀帝國式）；其餘節點照常在內部運作，不刪 |
| 文化 | 只保留會改變行為的特性 | 例：遷徙之民走得遠、守土的人不外移；純數值特性（荒年糧、採集加成類）不再新增 |
| 信仰 | 保留創立與傳播 | 信仰地圖模式、創立事件；信條效果只留內部 |
| 野生動物、獸襲 | 只留內部 | 「狼群出沒」與獸襲事件 |
| 天災、熱浪、野火 | 保留並加強 | 地圖上的過程（燒毀→焦土→長回來、淹水） |
| 地下城 | 凍結 | 停在「出現」（12-1 C4），做怪物之前不再加 |

- 已完成的內部效果不拆除（不改世界結果）；「只留內部」指不再擴充、不再接新的顯示。
- 08-8 文化剩餘效果：**遷徙之民路糧、守土照做**（改變遷徙行為）；**食人儀式荒年糧凍結**（純數值，留待日後以「看得見的事件」重新設計）。

## 3｜工程簡化（Claude 決定）

- 新系統走「**年結算＋事件**」的輕量路線：狀態年初定案、效果由事件推得，不再加週帳欄位與隊伍帳欄位。
- 週帳、因果驗證、存讀檔驗證只守核心（人口、糧食、遷徙）；新系統只需「事件只追加、存讀檔一致」。
- 一個新功能接的地方以「事件＋地圖＋編年史」三處為上限；詳情面板最多一行。

## 4｜之後的順序

1. **文化剩餘效果**：遷徙之民路糧、守土（08-8 B2 收尾）。
2. **WorldBox 那一半——讓變化動起來**：遷徙路線與人群、聚落外觀隨等級長大、天災過程、農田荒廢與重生。細節開工時在本章後面補節。
3. **十字軍之王那一半——讓紀錄成故事**：編年史把因果鏈串成段落（例：熱浪→饑荒→舉族遷徙→建立新村）；代表人物兩三行小傳。
4. **知識樹收斂顯示**：每個時代挑 3～5 個關鍵技術給玩家看。
5. 然後才回來加新機制，每一個都先過第 1 節的系統檢查。

08-14 第 2 節（穩定聚落少算）、第 4 節（多執行緒）依試玩是否卡頓再排入。
