# 08-22｜參考 CK3 的人物與戰爭（設計；分支章節）

> 使用者 2026-11-17：「相關的宗教、性格特質、身體特質、戰鬥、國家發起戰爭、戰爭進行方式…你都參考一下」。
> 本章列出要從 CK3 借的機制、與既有規則的對應、做的順序。每一節開工時另開子章（08-22a、08-22b…）寫細節與【TEMP】數值；
> 標 ★ 的是會改變玩法手感的取捨，開工前在 PR 問使用者。

## 1｜既有規則已經有的（不重做）

- 性格：領袖三項性格、八組十六項（08-10g、08-10h），影響宣戰、請願、忠誠——就是 CK3 的性格特質，之後只擴充效果。
- 宗教：文化與信仰特性池、信條與教義（設定檔 06A～06K）、聖地＝創立聚落（08-8）。
- 宣戰理由：聖戰（信仰不同）、納入異族（文化不同）、擴張；停戰；被征服的忠誠扣分（08-19e）。獨立派系、最後通牒、請願或獨立戰爭（08-19b）；篡位與內戰（08-19f）。
- 戰鬥：士兵有等級、依雙方等級算戰力（12-2c）。
- 怪物：使用者 2026-11-18 定案遊戲的兩個重點是文明發展與人類和怪物的領地爭奪（12-2h）。

## 2｜要借的（依做的順序）

1. **戰爭進行方式（08-22a）**：戰爭不再只看雙方死亡比例。
   - 攻方軍隊從首都出發，一週走幾格，到了圍攻目標省份；圍城數週後佔領（地圖上那個省份畫攻方顏色的斜紋——政治地圖已經會畫）。
   - 戰爭分數（−100～100）：打贏會戰、佔領省份加分，佔著戰爭目標每週再加；到 100 攻方勝，到 −100 或打滿兩年守方勝或白和平。
   - 守方派兵解圍：兩軍相遇就會戰。
2. **戰鬥（08-22b）**：會戰由統帥帶兵。
   - 統帥＝領袖或英雄；統帥值由性格（勇猛＋、怯懦－）、身體特質與英雄等級決定。
   - 地形：守方在丘陵、森林有加成；攻方渡河有懲罰。
   - 三階段（交鋒、主戰、追擊）只算結果，史書寫成一句：「某年，某某在某河畔擊潰某某的軍隊（攻方死 N、守方死 M）」。
3. **身體特質（08-22c）★**：天生的特質，會遺傳。
   - 體魄：強壯／健壯／虛弱。影響會戰與壽命。
   - 才智：聰慧／遲鈍。影響聚落學技術的速度。
   - 容貌：俊美／醜陋。影響婚配。
   - 罕見特質：巨人、侏儒、跛足、口吃。
   - 遺傳：父母有的，子女較容易有。
   - 後天：負傷、獨眼、跛腳（會戰後的統帥）。
   - ★ 使用者 2026-11-18 定案：身體特質只做小幅變動；另外加入**不可繼承的傳說特性**，可以大幅增加各項數值。
4. **宗教（08-22d）★**：
   - 狂熱度：信徒多、聖地都在手上就高；低了容易分裂出異端（新的信仰）。
   - 改宗：被征服的聚落慢慢改信上級的信仰。
   - 敵意：同源的信仰「誤入歧途」，不同源的「敵對」。敵意影響聖戰的宣戰機率與停戰長短。
   - ★ 使用者 2026-11-18 定案：要加入異端分裂。
5. **宣戰理由（08-22e）**：在既有的聖戰、納入異族、擴張之外，借 CK3 再加兩種。
   - 宣稱：舊王朝的子孫對失去的領地有宣稱，可以宣戰奪回。
   - 收復失地：二十年內被奪走的聚落可以宣戰收回。
   - 每種理由的戰爭目標與和約條件不同（整個勢力臣服、只割一個省份、只要求獨立）。

## 3｜畫面

- 政治地圖：戰爭中被佔領的省份畫攻方顏色斜紋；軍隊是地圖上的軍旗棋子，旗上寫兵力；會戰時兩軍之間出現交戰圖示與比分條（08-18m 已有，改沿省份移動）。
- 人物頁：性格、身體特質、統帥值；史書寫出統帥與會戰地點。

- 每一子章各自的 Core 測試與大地圖史書：戰爭有開始、圍城、會戰、和約；統帥與地點進入史書。
