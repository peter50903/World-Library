# 08-31｜勢力範圍圈選（分支章節）

> 使用者 2026-11-19：「點擊遊戲畫面選擇時，不要將正方形的地塊圈選出來，應該要以勢力範圍作為圈選範圍，取消選擇地塊的功能」。
> 修改：05-1 第 3 節與 08-18g 的點選層級（拿掉「地塊」這一層）；08-21 選到荒野、水、地下城時框格子。只改介面，不改世界、不改存檔。

## 1｜點到什麼

| 點到 | 選到 | 框起來的範圍 |
|---|---|---|
| 名牌、聚落 | 聚落 | 聚落的勢力範圍（省份） |
| 勢力範圍裡的空地 | 照地圖模式：地形＝這片範圍的聚落、勢力＝勢力、文化＝文化、信仰＝信仰 | 省份或整個勢力、文化、信仰 |
| 同一處再點 | 往上一層（聚落→勢力，文化、信仰模式再加上文化、信仰），輪完回到第一個 | 同上 |
| 怪物的地盤（地形、勢力模式） | 地下城（詳情標題寫地下城的名字） | 整片怪物地盤（提亮、金邊） |
| 荒野、海 | 不選 | — |

- **不再有「地塊」這一層**，地圖上也不再畫格子的方框。
- 遺跡、沒有地盤的地下城（沉寂中）沒有範圍可框：在標記外圍畫一圈金環。
- 滑鼠停在地圖上的提示照舊寫地形（只看、不選）。

## 2｜畫法

- 省份、勢力、文化、信仰沿用著色器的整片提亮與金邊（08-21）。
- 怪物地盤：地形貼圖的 G 通道改存地盤編號（1 起），著色器把選到的那一片提亮、邊緣畫金線，與勢力範圍同一種樣子、同一種扭曲邊界。

> 狀態：完成（待實測）。
