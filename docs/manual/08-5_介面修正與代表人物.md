# 08-5｜介面修正與代表人物（分支章節，修正 07-1 b 節代表人物職位）

> 使用者 2026-10-23 回報與裁決。

## 介面

1. 深海與淺灘圖塊的六角形比其他圖塊窄、矮，地圖拼不密合 → 依森林圖塊的六角形外框重新縮放兩張圖（素材檔直接修正）。
2. 按鍵音效太大聲 → 按鍵音量 −6 dB 改 −20 dB【TEMP】。
3. 左下功能列不畫分隔線。
4. 功能列的滑鼠提示看不清楚 → 提示改深色底、淺色字。
5. 滑鼠停在地圖格上只說明這一格是什麼（森林、草原、大海、河流、淺灘、某某村莊；遺跡另標）。
6. 點格查看詳情時，地圖上的這一格以黃色框標示；關閉詳情時取消。

## 代表人物（修正 07-1 b 節）

- 只有**權力者（村長）**與**持有專業知識的人**（木匠、鐵匠…）才算代表人物；採集、漁撈不是專業知識，取消這兩種代表。
- 專業知識的持有者隨知識樹出現（第 08-6 章），人數影響知識樹推進速度。
- 存檔第 23 版。
