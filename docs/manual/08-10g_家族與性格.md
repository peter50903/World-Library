# 08-10g｜家族、世襲與性格（08-10e 第 2 步之二；分支章節）

> 修正 07-1 b 節（村長＝最年長的成年人）。存檔改第 65 版（代表人物多兩欄；規則改變）。
> 使用者 2026-11-17：同意領袖世襲與性格，並且要有像十字軍之王那樣的家族概念。
> 參考十字軍之王：角色有特質、屬於家族，頭銜在家族裡傳承；絕嗣時換別的家族。

## 1｜世襲

- 領袖離世（老死、餓死、死於災禍或戰事）的那一週，由**子女輩**接任：本聚落比前任小 18～45 歲【TEMP】的成年人裡最年長的。
  繼承人沿用前任的姓、名字另取（不與父母同名），紀錄上記下父母是誰。
- 找不到子女輩的成年人（絕嗣）時，照原本的規則另推一位：最年長的成年人；主要文化是強人統治時推最壯年者（08-8 B2）。
  這位是新家族的第一代。開局的領袖、新建聚落的第一位領袖也是第一代。
- 人口仍是群體（07-1）：繼承人是從年齡群裡具名化的一個人，不追蹤每個人的親子關係；「子女」是年齡相符而被指定的繼承人。
- 其他職位（農師、木匠…）照舊，不世襲。

## 2｜家族

- 一位沒有承襲父母的領袖開創一個家族；之後一路世襲的都屬於這一家。家族由領袖紀錄的父母欄推得，不另存。
- 家族以「聚落＋姓」稱呼（例：伯恩坡的莫頓家）。姓只有 20 個，不同聚落可能同姓，那是不同的家族。
- 還沒做（之後的工作）：旁支、聯姻、家族之間的恩怨、家族名望；家族在多個聚落掌權（要先有分封）。

## 3｜性格

- 三組相反的性格：好戰／謹慎、寬厚／嚴苛、公正／暴虐。每位領袖在其中兩組各有一個，上任時由自己的實體亂數決定。
- 子女 50%【TEMP】承襲父母的一項。
- 效果（全部【TEMP】，看「王座所在聚落的領袖」）：

| 性格 | 效果 |
|---|---|
| 好戰 | 每次檢查宣戰的機率 +20% |
| 謹慎 | 兵力要達對方 200% 才宣戰（原本 120%） |
| 寬厚 | 下級請願成功率 +25% |
| 嚴苛 | 下級請願成功率 −25% |
| 公正 | 下級忠誠 +10（聚落詳情的忠誠明細多一項「領袖公正」） |
| 暴虐 | 下級忠誠 −10（「領袖暴虐」） |

## 4｜玩家看到

- **人物頁**（08-19c）：領袖多兩行——「家族：莫頓家（母親是前任村長艾妲·莫頓）」或「（這一家的第一代）」、「性格：好戰、嚴苛」。
- **史書**（08-10f）：每卷的人物句寫出性格與誰接任——「…第 62 年壽終（83 歲），由女兒艾琳·莫頓繼位」，
  或「…莫頓家就此失去權位，哈特家的艾妲·哈特接掌」。終章列出傳了兩代以上的家族（在哪裡、幾代、掌權年份、歷代名字）。
