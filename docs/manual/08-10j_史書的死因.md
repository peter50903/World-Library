# 08-10j｜史書每一卷寫出未得善終的死因（分支章節）

> 補 08-10e 第 3 節（每卷的生死一行）。只改史書的寫法，不改規則、存檔不改版。
> 來源：史書每卷只寫「234 人未得善終」，看不出那些年死於戰火、饑荒還是怪物。

## 1｜寫法

- 每卷最後一行：「這些年裡 670 人出生，44 人壽終，234 人未得善終（戰火 150、餓死 50、怪物 20、天災 10、野獸 4）；第 43 年末世上有 550 人。」
- 死因由事件的人數欄數得：戰火＝武力抗爭與征服戰爭的交戰；餓死＝聚落與遷徙途中餓死；怪物＝怪物襲擊與出兵討伐的陣亡；
  天災＝地震、龍捲風、隕石、洪水；野獸＝遷徙途中遭野獸襲擊。多的在前，同樣多時照這個順序。
- 年帳的非壽終死亡比事件數得多時，差額寫「其他」（之後再查是哪一種死亡沒有記事件）。
- 實作：Core `DemoSaga.DeathCause`、`DeathCauses`、`People`。

> 狀態：完成（待實測）。
