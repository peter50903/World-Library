# 08-19f｜繼位與內戰（分支章節）

> 修正第 08-19b 章第 2～6 節（忠誠度多三項；同文化的不滿者改組篡位派系）。存檔改第 55 版（規則改變）。

> 參考：十字軍之王（新君威望不足、宣稱者派系、逼宮與內戰、勝方換王朝）。第 10 章的完整繼承法與王朝之後再做。

## 1｜國王與王座

- **國王**＝王國（第 08-19e 章）王座所在聚落的村長。
- 王座預設在首都；逼宮或內戰成功後換到派系首領的聚落（新王朝）。
- 新王朝的聚落離開勢力（獨立、被征服、沒落）時，王座回到首都。
- 首都、國家與所有隸屬都不因換王而改變。

## 2｜繼位

- 王座所在聚落本週新任村長（老死、天災等原因換人）就記「繼位」。
- **新君即位**：156 週【TEMP】內，直屬臣屬忠誠 −15【TEMP】（新君威望不足，叛亂多在換王後發生）。

## 3｜篡位派系

- 只在征服時代、上級是王國時：不滿的臣屬如果與上級**同文化**，加入「篡位派系」（要推翻國王）；**異文化**照舊加入獨立派系。
- 加入、退出、首領、不滿累積 26 週的規則照第 08-19b 章第 3 節。
- **行動**（派系兵力 ÷ 上級方兵力）：

| 比例 | 結果 |
| --- | --- |
| 不到 80% | 不行動，繼續等（篡位派系不請願） |
| 80%～150% | 要求國王退位被拒，爆發**內戰** |
| 150% 以上 | 國王被迫退位，**篡位**成功 |

## 4｜內戰

- 交戰、比分、勝負、維持原狀同獨立戰爭（第 08-19b 章第 5 節）。
- **打贏**：篡位——王座換到首領的聚落。
- **打輸**：照舊被鎮壓（260 週內不再加入派系，忠誠 +25）。

## 5｜忠誠度新增三項

| 因素 | 加減 |
| --- | --- |
| 新君即位（156 週內） | −15 |
| 國王出身於此（王座所在的臣屬） | +20 |
| 擁立了現任國王（260 週內；這段期間也不加入派系） | +25 |

## 6｜事件

| 事件 | 人數欄 | 編年史 |
| --- | --- | --- |
| 繼位 | 新國王的實體編號 | 重大（勢力） |
| 內戰 | 上級編號 | 重大（勢力） |
| 篡位 | 原上級（王國）編號 | 重大（勢力） |

- 內戰的交戰、失敗沿用獨立戰爭交戰、脫離失敗兩種事件（原因寫「內戰」）。
- 三種事件都跳通知；聚落小史都記。

## 7｜玩家看到

- 聚落詳情與勢力頁：「國王：名字（年齡，某某王朝，第幾年即位）」。
- 分裂鬥爭段寫「內戰（要推翻國王）」；地圖上的交戰與獨立戰爭相同（金色 ⚔，提示框寫內戰）。
- 世界法則「叛亂與獨立」也管內戰。
