## 使用者意見（已定案）

1. 3 倍速以上拖曳地圖會卡頓。
2. 人口到上限附近後，除非有意外中斷食物（後續時代由事件產生），每個村子應達到人口平衡、維持溫飽，中後期幾乎只剩老死。
3. 聚落要記錄建立至今幾年，以及聚落小史（第幾年移居開拓、第幾年人口成長成為村莊…）。
4. 世界控制台是開發用資訊；正式版右側該放世界紀錄（依時間逐條列出，點一筆才顯示詳情）。地圖模式與工具兩排圖示合併成一條功能列，與時間控制並排置底。
