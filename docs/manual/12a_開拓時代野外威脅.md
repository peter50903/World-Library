# 12a｜開拓時代的野外威脅（第 12 章提前切片）

> 使用者 2026-10-23：開拓時代出現人類生活圈外的野生動物攻擊、天災、地下城。裁決：
> ① 野獸**只攻擊生活圈外的人**（遷徙隊伍、開拓隊、婚嫁途中；聚落與它的採集範圍內安全）；
> ② 地下城**出現、養怪，滿了會溢出**（攻略要等城邦的冒險者公會）。
> 本切片遵守第 12 章已定案規則（族群有棲地與承載、災害有地理前提且作用於真實實體、地下城有限核心生成）。數值一律【TEMP】。

## 1｜生活圈

- 生活圈＝聚落格與它的採集範圍（六鄰格）。生活圈以外的森林、草原格是**野地**。
- 野生動物、溢出的魔物只住在野地；聚落新建或成為遺跡時，野地隨之改變。

## 2｜野生動物（C1）

| 項目 | 規則【TEMP】 |
|---|---|
| 出現 | 進入開拓時代那週，每格野地放入承載量的獸群（第 12 章 MON_POP：真實族群，不臨時生成） |
| 物種 | 兩種聚合族群：草食獸（鹿群，獵物）、掠食獸（狼群） |
| 承載 | 森林格草食 6、草原格草食 8；掠食＝附近草食的五分之一 |
| 繁殖 | 每年一次：草食＋20%、掠食依獵物＋10%，不超過承載；超載的死亡 |
| 狩獵 | 會狩獵的聚落每週從 2 格內的野地獵草食獸（每 5 名成年人 1 頭），每頭化為糧食 20，獸產（肉、皮）大類改為取得得到；週帳新欄位「獵得的糧食」 |
| 畜牧 | 2 格內有草食獸時，畜牧分支開始有從業者 |

## 3｜野獸攻擊（C2）

- 只攻擊生活圈外的人：途中隊伍每週所在格與鄰格的掠食獸越多，越可能被襲（每 10 頭掠食獸 5%，最多 30%）；被襲時死 1～2 人（局部亂數，以隊伍編號與週次為鍵）。
- 出發聚落會弓箭：損失減半；會巡守與圍獵：被襲機率再減半。
- 記「遭野獸襲擊」事件（根因）；遷徙帳新欄位「遭襲死亡」。之後的傷口照護以此為實踐條件。

## 4｜天災（C3）

| 天災 | 地理前提 | 後果【TEMP】 |
|---|---|---|
| 洪水 | 鄰河聚落，每年 3% | 存糧減半；開墾中的農田進度歸零 |
| 風暴 | 鄰海聚落，每年 2% | 存糧減三成 |
| 野火 | 可及森林的聚落，每年 2% | 存糧減三成；附近一格野地的獸群減半 |

- 每年結算一次，局部亂數以聚落編號與年份為鍵；記「天災」事件（根因）與聚落小史；週帳新欄位「天災損失的糧食」。
- 天災不造成直接死亡（之後的缺糧照常致死），不拿來平衡強弱（49B）。

## 5｜地下城（C4）

| 項目 | 規則【TEMP】 |
|---|---|
| 出現 | 開拓時代起，世界目標數量＝陸地格數／150（至少 1）；不足時每年在離聚落 3 格以上的野地生成一座（第 12 章 DUN_TARGET） |
| 規模 | 1～10 層（小型），核心預算＝層數×20 隻魔物 |
| 養怪 | 核心每年生成預算的十分之一，魔物在地下城內繁殖（每年＋10%）；被地下城束縛，不會出來 |
| 溢出 | 魔物數達層數×30 時溢出：魔物解除束縛，成為附近野地的掠食族群（併入野獸攻擊），地下城魔物歸零、核心預算扣除已生成的數量 |
| 攻略 | 暫無（冒險者公會在城邦等級出現後） |
| 核心內容 ★ | 能生成哪些物品與魔物類別，第 12 章開工攻略時再定 |
