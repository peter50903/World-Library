# 08-20c｜KayKit 建築用在正式 2D 地圖（分支章節）

> 修正第 08-20、08-20a、08-20b 章（三個等角原型都不採用）。使用者 2026-11-14 晚：還是用回原本的 2D；建築的表現、建築之間串聯在一起的感覺很優秀，要沿用；
> 要像素化（樣式可以改）；地塊、森林照原本的；整體只參考建築。

## 1｜範圍

- 只換**建築**與**聚落的串聯**；地表（方格、生態區、自然交界的參差）、森林與樹、天災、人物、介面全部照原本。
- 原型的地塊沒有過渡，是原型自己的畫法；正式地圖本來就有自然交界的參差（第 08-18b 章），不受影響。

## 2｜建築素材：KayKit 模型烘焙成像素圖

- `tools/kaykit_bake.py` 把 `godot/assets/kaykit/` 的模型（CC0）烘成 `godot/assets/px2/kk_*.png`，與地表同一密度（每格半徑 48 圖像素），登記在 manifest（類型「像素零件」、生成方式「程式烘焙」）。
- 視角：鏡頭在南方上空往北看，俯角 40 度【TEMP，在工具裡】，光從左上——與原本建築的「俯視略帶正面」相同。
- 像素化：4 倍解析度算圖後縮小、透明度二值化、顏色量化、外圍 1 像素深色描邊。樣式要改時改工具再重烘即可。
- 文化色：模型的藍色屋頂與旗幟烘成灰階，地圖上整張染文化色（第 08-18d 章的染色）；石頭與牆面加暖，不會被誤染。
- 對應（四個方向＝門朝南、東、北、西）：

| 建築 | 模型 |
|---|---|
| 木屋 | home_A |
| 房子 | home_B |
| 石屋 | tavern |
| 村會所 | tavern（大） |
| 鎮會所 | barracks |
| 市集 | market |
| 神殿 | church |
| 鐵匠 | blacksmith |
| 工坊 | lumbermill |
| 主樓 | castle（不分方向） |
| 井、瞭望塔 | well、tower_A（不分方向） |

| 木柵 | fence_wood_straight |

- 沒有對應模型的（帳篷、穀倉、窯、學校、抄經房、小祠）沿用第五批素材。

## 3｜串聯感（沿用 08-20b 的擺放規則）

- **門朝街**：每棟建築依貼著的道路決定方向（南、東、西、北的順序），用對應方向的素材——不再全部朝南。
- **城鎮圍木柵**（原本只有城市以上有牆）；城市以上是石牆；道路穿過的地方是城門。
- **首都雙層石牆**：主樓外圍再一圈內城牆，道路穿過處是內城門（沒有路穿過時開在主樓正面那一邊）。
- 道路、廣場、房子貼著道路的規則照第 08-18b 章。
