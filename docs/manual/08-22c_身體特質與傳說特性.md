# 08-22c｜身體特質與傳說特性（分支章節）

> 體魄的壽命效果見 08-22h（強壯比較長壽、虛弱比較短命、龍血長壽）。

> 參考 CK3 的先天特質（08-22 第 2 節第 3 項）。使用者 2026-11-18 定案：身體特質只做小幅變動；另外加入**不可繼承的傳說特性**，可以大幅增加各項數值。
> 只有具名人物（領袖、英雄）有特質；性格照 08-10g、08-10h。

## 1｜身體特質【TEMP】（天生、會遺傳、效果小）

| 組 | 正面 | 負面 | 效果 |
|---|---|---|---|
| 體魄 | 強壯 | 虛弱 | 打仗時讓對方死傷 ±10% |
| 才智 | 聰慧 | 遲鈍 | 領導的聚落研究 ±10% |
| 容貌 | 俊美 | 醜陋 | 下級忠誠 ±5 |

- 每組各 12% 是正面、12% 是負面，其餘沒有；同一組不會兩邊都有。
- 父母有同一組的特質時 50% 遺傳（沒遺傳到再照機率抽）。
- 壽命與婚配暫不受影響（之後依人口曲線再決定要不要小幅加上）。

## 2｜傳說特性【TEMP】（不會遺傳、罕見、效果大）

| 傳說 | 效果 |
|---|---|
| 天命 | 下級忠誠 +20；打仗時讓對方死傷 ×130% |
| 龍血 | 打仗時讓對方死傷 ×160% |
| 賢者 | 領導的聚落研究 +50% |
| 聖者 | 下級忠誠 +25 |

- 新任領袖 2%、英雄 40% 天生帶一項；子女不會承襲。
- 與性格、身體特質相乘（例：勇猛＋強壯＋龍血 → 對方死傷 ×219%）。英雄帶兵（08-22f）時，英雄的特質不另外算（看領袖的）。

## 3｜畫面與文字

- 人物頁的「性格」一行與逐項說明：傳說特性在前，接著性格、身體特質；每項一句效果（註明會不會遺傳）。
- 史書的人物與英雄括號裡同樣列出（例：「卡菈·伍德（士兵出身；龍血、好戰、狡詐、虔誠、強壯）」）。
