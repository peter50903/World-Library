# 08-10i｜英雄與傳說物品（08-10e 第 2 步之三；分支章節）

> 接續 08-10e 第 3 節第 2 步與 12-2d（冒險者移除後英雄的來源）。存檔改第 68 版（規則改變）。
> 使用者 2026-11-17：英雄來自「成名的士兵」與「領袖的家族成員」兩種。

## 1｜英雄

- **成名**：一個聚落的人馬殺光一個地下城的怪物（地下城沉寂）的下一週，帶隊的人具名成為這個聚落的英雄（代表人物的新職位「英雄」）。
  算哪個聚落的功勞：同一週在那個地下城最後一筆擊殺的聚落。每個聚落同時最多一位在世的英雄；英雄不補任。
- **出身**：聚落的領袖有子女輩的成年人（比領袖小 18～45 歲）時，50%【TEMP】是領袖的子女——沿用家族的姓、記下父母、可能承襲父母的性格；
  否則是士兵出身——未滿老年的成年人裡最年輕的，另取姓名。
- **性格**：英雄與領袖一樣有三項性格（08-10h）；目前只是人物的描寫，性格的效果看的是領袖。
- **效果**：英雄在世時，本聚落士兵的等級 +1【TEMP】（12-2c 的戰力與能不能殺光）。
- 英雄是群體人口裡具名化的一個人，會老死、餓死、死於災禍（與其他代表人物相同）。

## 2｜傳說物品

- 地下城核心留下的裝備（12-1：核心可以產生怪物、材料與裝備）。每位英雄成名時得到一件。
- 名稱＝地下城名稱＋「之」＋劍、槍、弓、盾、冠、甲、杖、斧其中之一（由事件編號決定）。例：「灰燼洞窟之劍」。
- 下落：英雄在世由英雄持有；領袖家族出身的英雄死後由家族收藏；士兵出身的英雄死後下落不明。
- 物品與下落都由英雄的登記紀錄與「地下城沉寂」事件推得，不另存。目前沒有效果，只有履歷。

## 3｜玩家看到

- **人物頁**：英雄多「家族／出身」「性格」「事蹟：第 N 年帶隊殺光某地下城的怪物，得到某物」。
- **史書**：每卷的「英雄」句——哪一年、哪裡的誰（出身；性格）殺光哪個地下城、得到什麼、後來怎麼過世；終章列出每件傳說物品的下落。
- 聚落小史與編年史（一般事件）照常記下「某人成為英雄」。
- 實作：Core `DemoHeroes`（`Deeds`、`Legends`、`ItemName`）、`DemoHumanLifecycle.Representatives`（成名）、`DemoCombat.Force`（+1）、
  `DemoSagaCast.Heroes`／`Relics`。
